Очередь уведомлений (toasts)

Каждое уведомление хранит свой id и тип (обычное или ошибка), само исчезает через несколько секунд и закрывается кликом в любом месте. На каждом элементе списка это уже два атрибута — :class для подсветки ошибки и @click для закрытия — поэтому они собраны в один именованный набор entry и подключены одной директивой v-bind="entry" вместо перечисления по отдельности на каждом клонированном v-each-элементе. 

document.addEventListener('youla:init', () => {
  Youla.data('toasts', () => ({
    items: [],
    counter: 0,
    notify(message, type = 'info') {
      let id = ++this.counter;

      this.items = [...this.items, { id, message, type }];

      setTimeout(() => this.dismiss(id), 3000);
    },
    dismiss(id) {
      this.items = this.items.filter(item => item.id !== id);
    },
    entry: {
      ':class': "{ 'toast--error': toast.type === 'error' }",
      '@click': 'dismiss(toast.id)',
    },
  }));
});

<div v-data="toasts">
  <button type="button" @click="notify('Файл сохранён')">Показать уведомление</button>
  <button type="button" @click="notify('Что-то пошло не так', 'error')">Показать ошибку</button>

  <div v-each="toast in items" v-bind="entry" class="toast">
    <span v-text="toast.message"></span>
  </div>
</div>

Ключи набора entry — строки-выражения, а не методы: как и в примере v-bind внутри v-each, только строки получают доступ к переменной цикла (toast) — метод получил бы только this с данными компонента, без неё.

Клик по самому уведомлению закрывает его — отдельная кнопка «×» больше не нужна, а dismiss(toast.id) удаляет из массива именно этот элемент, не трогая соседние и их собственные таймеры. В реальном проекте список уведомлений обычно закрепляют в углу экрана через position: fixed — здесь он оставлен в потоке страницы, чтобы не перекрывать остальную часть документации.
