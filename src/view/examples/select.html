Список выбора (u-select)

Директива u-select — адаптер для SlimSelect: превращает обычную разметку <select>/<option>/<optgroup> в стилизованный список с поиском, множественным выбором, картинками и иконками у пунктов — сама библиотека подключена в проект напрямую, ставить и загружать её отдельно не нужно.

Атрибут multiple на <select> — обычный HTML-атрибут, но директива на него реагирует: по умолчанию для множественного выбора включаются hideSelected (выбранные пункты исчезают из списка) и выключается closeOnSelect (список не закрывается после каждого клика). Значение самой директивы, если оно задано, — обычное JS-выражение с объектом настроек, как и везде в Youla.js; оно подмешивается в настройки SlimSelect, переопределяя эти и любые другие дефолты.

Опции вкратце

Опция Описание По умолчанию
showSearch Строка поиска по пунктам списка. false
closeOnSelect Закрывать ли список сразу после выбора пункта. true, для multiple — false
hideSelected Прятать ли уже выбранные пункты из выпадающего списка. false, для multiple — true
allowDeselect Разрешить снимать выбор с одиночного <select> кликом по уже выбранному пункту. false
placeholderText, searchPlaceholder Текст заглушки в самом поле и в строке поиска. стандартный текст библиотеки
minSelected, maxSelected Ограничивают число выбранных пунктов в multiple-режиме. 0 (без ограничений)

Одиночный выбор с иконками

data-icon у <option> добавляет иконку перед текстом пункта — значение подставляется как есть в class, поэтому подходит любой набор иконок, здесь — Phosphor. 

<select u-select>
  <option value="js" data-icon="ph ph-brackets-curly">JavaScript</option>
  <option value="py" data-icon="ph ph-terminal-window">Python</option>
  <option value="rs" data-icon="ph ph-gear">Rust</option>
  <option value="go" data-icon="ph ph-lightning">Go</option>
</select>

Множественный выбор

Достаточно атрибута multiple — hideSelected и отключённый closeOnSelect включаются сами, без единой опции в разметке. 

<select u-select multiple>
  <option value="html">HTML</option>
  <option value="css">CSS</option>
  <option value="js" selected>JavaScript</option>
  <option value="ts">TypeScript</option>
  <option value="node" selected>Node.js</option>
</select>

Optgroup, картинки и описания

<optgroup> превращается в заголовок группы, а data-image и data-description у пункта — в аватар и подпись под именем, как в выборе ответственного за задачу. 

<select u-select>
  <optgroup label="Дизайн">
    <option value="anna" data-image="avatar-anna.svg" data-description="UI/UX дизайнер">Анна</option>
    <option value="oleg" data-image="avatar-oleg.svg" data-description="Иллюстратор">Олег</option>
  </optgroup>
  <optgroup label="Разработка">
    <option value="ivan" data-image="avatar-ivan.svg" data-description="Frontend">Иван</option>
    <option value="maria" data-image="avatar-maria.svg" data-description="Backend">Мария</option>
  </optgroup>
</select>

Свои настройки SlimSelect: поиск и лимит выбора

Значение директивы передаётся прямо в настройки SlimSelect. Здесь оно включает поиск (по умолчанию выключен) и ограничивает выбор двумя тегами через maxSelected. 

<select
  u-select="{ showSearch: true, searchPlaceholder: 'Найти тег', placeholderText: 'До 2 тегов', maxSelected: 2 }"
  multiple
>
  <option value="frontend">Frontend</option>
  <option value="backend">Backend</option>
  <option value="devops">DevOps</option>
  <option value="design">Дизайн</option>
  <option value="mobile">Mobile</option>
</select>
