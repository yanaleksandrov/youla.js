Список задач

Список задач — типовой сценарий, который нужен в любом трекере с отметками: ввести текст, добавить задачу, отметить её выполненной, удалить одну задачу или очистить список целиком. Кнопка «Добавить» отключена, пока поле пустое, отмеченная задача зачёркивается, а сам список вместе с кнопкой «Очистить всё» появляется только тогда, когда в нём есть хотя бы одна задача. Ниже — весь код, который для этого нужен: данные и обработчики в Youla.data и разметка, которая их использует. Директивы, которые здесь участвуют — v-prop, v-each, v-show и v-bind — разобраны каждая на своей странице. 

document.addEventListener('youla:init', () => {
  Youla.data('todo', () => ({
    value: '',
    tasks: [],
    adder: {
      '@click': "tasks = [...tasks, {title: value, checked: false}]; value = ''",
      ':disabled': '!value.trim()',
    },
    checkbox: {
      '@change': 'task.checked = !task.checked',
      ':checked': 'task.checked',
    },
    status: {
      'v-text': 'task.title',
      ':class': "task.checked && 'strike'",
    },
    remover: {
      '@click': 'tasks = tasks.filter((_, i) => i != index)',
    },
    clearer: {
      '@click': 'tasks = []',
    },
  }));
});

<div v-data="todo">
  <p>Добавить задачу:</p>
  <input placeholder="Введите новую задачу..." v-prop="value" />
  <button type="button" v-bind="adder">Добавить</button>

  <div v-show="tasks.length" hidden>
    <p>Список задач:</p>
    <ul>
      <li v-each="(task, index) in tasks">
        <label>
          <input type="checkbox" v-bind="checkbox"> <span v-bind="status"></span>
        </label>
        <button v-bind="remover">Удалить</button>
      </li>
    </ul>
    <button v-bind="clearer">Очистить всё</button>
  </div>
</div>

Чтобы использовать этот пример в своём проекте, достаточно поменять форму данных: вместо title и checked — свои поля задачи, вместо tasks — свой список. Если задаче нужно больше действий — например, редактирование, приоритет или срок — добавьте ключ в существующий набор (status, remover) или заведите новый по той же схеме: разметка внутри v-each при этом не меняется, новое поведение появляется через v-bind на нужном элементе. Так список остаётся расширяемым без правок HTML — меняется только объект данных.
