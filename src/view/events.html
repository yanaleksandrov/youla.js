События

Youla.js упрощает прослушивание событий браузера и реагирование на них — без ручной работы с addEventListener и без лишнего кода вокруг каждого обработчика.

Отслеживание простых событий

Для обработки событий используется атрибут с синтаксисом вида @event-name, а также его эквиваленты с модификаторами. Рассмотрим пример простого прослушивания события при клике на кнопку:

В этом примере кнопка реагирует на событие click, и при нажатии на экране появляется системное окно с сообщением «Привет 👋», сформированным прямо в выражении. 

<div u-data>
  <button @click="alert('Привет 👋')">Скажи привет</button>
</div>

Вы можете прослушивать любое событие браузера по его имени: @mouseenter, @keyup, @submit и так далее — весь этот синтаксис допустим и работает одинаково.

Кроме того, библиотека поддерживает два нестандартных события: @load — срабатывает при инициализации элемента, и @intersect — когда элемент появляется в области видимости.

Модификаторы

Youla.js предлагает ряд модификаторов для настройки поведения слушателей событий — от предотвращения действия по умолчанию до фильтрации по нажатой клавише.

.prevent

Это эквивалент вызова .preventDefault(). В примере ниже форма не отправляется на эндпоинт /foo и страница не перезагружается — модификатор перехватывает отправку до того, как это сделает браузер.

Форма «отправлена» без перезагрузки страницы ✅

<div u-data="{ submitted: false }">
  <form @submit.prevent="submitted = true" action="/foo">
    <button>Submit</button>
  </form>
  <p u-show="submitted">Форма «отправлена» без перезагрузки страницы ✅</p>
</div>

.stop

Это эквивалент вызова .stopPropagation(). В примере ниже клик по кнопке не доходит до родителя, потому что модификатор останавливает всплытие события — счётчик клика по контейнеру не увеличивается.

Без модификатора .stop событие поднялось бы выше по дереву DOM, и сработал бы обработчик @click, установленный на родительском <div>, увеличив оба счётчика сразу.

Кликов по контейнеру: 
<div u-data="{ containerClicks: 0, buttonClicks: 0 }" @click="containerClicks++">
  Кликов по контейнеру: <span u-text="containerClicks"></span>
  <button @click.stop="buttonClicks++">Click Me (кликов: <span u-text="buttonClicks"></span>)</button>
</div>

.outside

Удобный помощник для закрытия элемента по клику за его пределами — пригодится для выпадающих списков, поповеров, модальных окон и похожих интерфейсов.

В примере ниже нажмите «Открыть», а затем щёлкните в любом месте страницы за пределами блока — он закроется благодаря модификатору .outside у события клика.

Контент... 
<div u-data="{ open: false }">
  <button @click="open = ! open">Открыть</button>
  <div u-show="open" @click.outside="open = false">
    Контент...
  </div>
</div>

.top, .bottom, .left, .right для @scroll

Модификаторы края вызывают обработчик @scroll, только когда прокрутка находится у указанного края или ближе заданного отступа к нему. Это удобно для бесконечных списков, подгрузки данных в обе стороны и отметки о том, что пользователь дочитал страницу.

Модификатор Когда срабатывает
.topУ верхнего края
.bottomУ нижнего края
.leftУ левого края
.rightУ правого края
.blockУ верхнего или нижнего края
.inlineУ левого или правого края
.<число>pxШирина зоны края в пикселях: .bottom.200px
.lazyОтключает начальный вызов: обработчик ждёт первой прокрутки
.<число>%Ширина зоны края в процентах от высоты области прокрутки (top, bottom) или её ширины (left, right): .bottom.50%

Без отступа допуск — 1px. Отступ один на обработчик и действует на все его края. Несколько краёв объединяются через «или»: @scroll.top.bottom — то же, что @scroll.block. Модификаторы работают вместе с .window, .document, .passive, .delay и .once, а также в наборах u-bind.

Обработчик вызывается на каждом событии scroll в зоне края, поэтому защиту от повторных вызовов (например, флаг загрузки) нужно делать в самом обработчике. Кроме того, сразу после подключения он вызывается один раз, если прокрутка уже в зоне края — например, когда содержимое помещается целиком. С .once этот начальный вызов тоже считается, а .lazy его отключает — например, для .top, который в начале прокрутки почти всегда в зоне края.
Строк: 
<div class="list" @scroll.passive.bottom.200px="loadMore()">...</div>

<div class="grid" @scroll.passive.top.50%="load('before')" @scroll.passive.bottom.50%="load('after')">...</div>

<body @scroll.window.passive.bottom.once="footerReached = true">...</body>

.window

Регистрирует обработчик на window вместо самого элемента — удобно, когда событие может произойти в любом месте страницы, а не только на этом элементе.

Фрагмент ниже перехватывает нажатие «ctrl + s» где угодно на странице, даже если фокус находится не на этом <div>, а совсем на другом элементе или в другой форме.

Нажмите Ctrl + S в любом месте страницы — фокус может быть где угодно, а не только здесь. 
<div u-data @keydown.prevent.ctrl.s.window="alert('No need save')">...</div>

.self

Вызывает обработчик, только если событие произошло на самом элементе, а не всплыло от вложенного.

Клики по фону: 
<div u-data="{ hits: 0 }" @click.self="hits++">
  Клики по фону: <span u-text="hits"></span>
  <button type="button">Клик по кнопке не считается</button>
</div>

.form

Слушает событие формы, в которой находится элемент: срабатывает на самой форме и на всех её полях, включая поля, привязанные к ней атрибутом form за её пределами. Удобно для компонентов, которые реагируют на изменения или сброс всей формы, например для автосохранения. 

<form>
  <input type="text" name="title">
  <button type="reset">Сбросить</button>
  <p u-data="{ status: 'Без изменений' }"
     @input.form="status = 'Изменено поле ' + $event.target.name"
     @reset.form="status = 'Форма сброшена'"
     u-text="status"></p>
</form>

.enter, .esc, .ctrl и другие клавиши

Модификатор, не входящий в список выше, работает как фильтр по клавише: обработчик сработает, только если нажатая клавиша ему соответствует, а не любая другая.

Для частых клавиш есть готовые псевдонимы: .enter, .esc/.escape, .tab, .space, стрелки .up/.down/.left/.right, .delete/.backspace. Для остальных клавиш используйте их название напрямую, как .s в примере выше.

Системные клавиши .ctrl, .alt, .shift и .meta требуют, чтобы клавиша была зажата в момент события, и свободно сочетаются с другими модификаторами — так в примере выше собран ctrl + s. 

<input u-data @keydown.enter="alert('Отправлено')">

.once

Гарантирует, что обработчик сработает только один раз за всё время жизни элемента — повторные клики или события того же типа больше не вызовут его снова. 

<button u-data @click.once="alert('Я появлюсь только один раз')">Кликни</button>

.delay[.500ms]

Откладывает вызов обработчика на заданное время. Если событие срабатывает снова до истечения задержки (например, пользователь продолжает печатать), таймер сбрасывается и отсчёт начинается заново.

В примере ниже обработчик input сработает через 500 мс после того, как пользователь перестанет печатать — классический приём debounce, снижающий число лишних запросов и обработок. 

<input u-data @input.delay.500ms="alert('Я вызван')">
