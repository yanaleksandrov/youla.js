Загрузчик аватарки

Форме профиля обычно нужен загрузчик фото: показать превью сразу после выбора файла, до всякой отправки на сервер, и чем-то заменить пустое место, пока файл не выбран — обычно инициалами пользователя. Написанное вручную, это каждый раз одна и та же связка FileReader, запасного состояния и очистки input[type="file"] по кнопке «Удалить». 

Youla.data('avatar', () => ({
  content: '', image: '',

  field: {
    'v-prop': 'content',
  },
  picture: {
    ':style': "image && `background-image:url(${image})`",
  },
  initials(letters = 2) {
    return {
      'v-show': '!image',
      'v-text': `content && getInitials(content, ${letters})`,
    }
  },
  uploader: {
    '@change': 'add($event)',
  },
  remover: {
    '@click': 'remove($event)',
    'v-show': 'image',
  },

  add(event, callback) {
    let file = event.target.files[0];
    if (file) {
      let reader = new FileReader();
      reader.onload = e => {
        this.image = e.target.result;
      };
      reader.readAsDataURL(file);
    }

    if (callback) {
      callback();
    }
  },
  remove(event) {
    let root  = event.target.closest('[v-data]'),
      input = root && root.querySelector('input[type="file"]');
    if (input) {
      input.value = '';
    }
    this.image = '';
  },
  getInitials(string, letters = 2) {
    const wordArray = string.split(' ').slice(0, letters);
    if (wordArray.length >= 2) {
      return wordArray.reduce((accumulator, currentValue) => `${accumulator}${currentValue[0].charAt(0)}`.toUpperCase(), '');
    }
    return wordArray[0].charAt(0).toUpperCase();
  },
}))

<div v-data="avatar">
  <input type="text" v-bind="field" placeholder="Введите имя">

  <div class="avatar-circle" v-bind="picture">
    <span v-bind="initials(1)" hidden></span>
  </div>

  <input type="file" accept="image/*" v-bind="uploader">
  <button type="button" v-bind="remover" hidden>Удалить</button>
</div>

image хранит выбранный файл как data:-URL — этого достаточно для превью, но для реальной загрузки файл нужно дополнительно отправить на сервер, сам компонент этим не занимается.

Как пользоваться

Набор Куда навесить Что делает
field текстовое поле имени v-prop двусторонне связывает поле с content
picture контейнер превью :style подставляет image фоном, пока он не пуст
initials(letters) заглушка внутри превью v-show показывает её, пока файла нет; v-text — первые letters букв content (по умолчанию 2)
uploader input[type="file"] @change читает выбранный файл в image
remover кнопка «Удалить» v-show появляется, только когда image заполнен; @click очищает и image, и сам input[type="file"]

type и accept у обоих input и кнопки — обычные native- атрибуты, поэтому они остаются прямо в разметке, а не переезжают в Youla.data: в наборы v-bind идут только методы, события, :attribute и директивы.

И add, и remove получают событие первым аргументом (add($event), remove($event)) — event.target внутри них и есть тот элемент, на котором сработало событие, доступа к нему через this.$el внутри обычного метода нет.
