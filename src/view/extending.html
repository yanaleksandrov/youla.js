Extending

Youla.js не ограничивается встроенными директивами и специальными переменными — можно регистрировать собственные v-* директивы и методы, доступные по имени $ внутри выражений, точно так же, как встроенные v-show или $refs.

Хук youla:init

Прежде чем Youla.js начнёт искать на странице элементы с v-data и инициализировать компоненты, документ получает событие youla:init. Это единственный момент, когда регистрация новой директивы или метода гарантированно происходит раньше, чем они понадобятся — весь код регистрации оборачивают в его обработчик. 

document.addEventListener('youla:init', () => {
  // здесь регистрируются директивы, методы и данные компонентов
});

Пользовательские директивы

Youla.directive(имя, callback) регистрирует директиву v-имя. После этого атрибут с таким именем на любом элементе внутри компонента ведёт себя как обычная директива Youla.js: вычисляется заново при каждом изменении данных, от которых зависит его выражение, и вызывает callback с результатом.

Параметр Значение
el DOM-элемент, на котором объявлена директива
output Результат вычисления выражения из значения атрибута
attribute Разобранный атрибут: expression, modifiers и другие поля
component Компонент-владелец элемента — доступ к его реактивным данным через component.data 
document.addEventListener('youla:init', () => {
  Youla.directive('uppercase', (el, output) => {
    el.textContent = String(output).toUpperCase();
  });
});

<div v-data="greeting">
  <input v-prop="name" />
  <p v-uppercase="name"></p>
</div>

Директива вызывается заново по тем же правилам, что и встроенные: Youla.js сам следит, какие свойства читает выражение из значения атрибута, и перезапускает callback, только когда одно из них меняется — писать код отслеживания изменений внутри директивы не нужно.

Регистрировать директиву с уже занятым именем нельзя — Youla.js оставит первую регистрацию как есть и выведет предупреждение в консоль, вместо того чтобы молча её перезаписать.

Пользовательские методы

Youla.method(имя, callback) регистрирует метод, доступный внутри обработчика любого события (@click, @input и т.п.) как $имя — рядом со встроенными $el, $event, $refs и $root.

В отличие от директивы, callback здесь — не сам метод, а фабрика: она вызывается один раз на каждое обращение к $имя с текущими el и component, а возвращённая ею функция и есть то, что реально вызывается в выражении.

Параметр фабрики Значение
event Объект события, вызвавшего обработчик
el Элемент, на котором объявлен обработчик события
component Компонент-владелец — доступ к его реактивным данным через component.data 
document.addEventListener('youla:init', () => {
  Youla.method('roll', () => () => Math.ceil(Math.random() * 6));
});

<div v-data="{ value: 1 }">
  <button type="button" @click="value = $roll()">Бросить кубик</button>
  <span v-text="value"></span>
</div>

Как и с директивами, имя, которое уже занято, повторно зарегистрировать нельзя — Youla.js предупредит об этом в консоли и оставит первую регистрацию без изменений.

Пользовательские переменные

Youla.variable(имя, callback) регистрирует переменную $имя, доступную в любом выражении — и в директивах, и в обработчиках событий — точно так же, как встроенные $el, $event, $refs и $root (подробнее о них — на странице Variables).

Как и с методами, callback здесь — фабрика, а не готовое значение: она вызывается заново при каждом вычислении выражения, а её результат становится $имя именно для этого вычисления.

Параметр фабрики Значение
root Корневой элемент компонента — тот, на котором объявлен v-data
el Элемент, на котором объявлено вычисляемое выражение
event Объект события — только внутри обработчика события, иначе undefined 
document.addEventListener('youla:init', () => {
  Youla.variable('now', () => new Date().toLocaleTimeString());
});

<div v-data="{ tick: 0 }">
  <button @click="tick++">Обновить время</button>
  <p>Сейчас: <strong v-text="`${$now} (обновлений: ${tick})`"></strong></p>
</div>

Сейчас:

$now не хранится в данных компонента и не отслеживается как зависимость — он просто пересчитывается каждый раз, когда элемент, использующий его, перерисовывается по любой другой причине (здесь — по клику, меняющему tick). Если в выражении не читать ни одного реального свойства данных, оно вычислится один раз при инициализации и больше не обновится, даже если значение $имя в этот момент изменилось бы.

Имена $el, $event, $refs и $root зарезервированы встроенными переменными — Youla.variable() откажется их переопределить и предупредит об этом в консоли. Как и с директивами и методами, повторная регистрация уже занятого имени тоже не перезапишет первую.
