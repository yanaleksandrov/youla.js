Конструктор бандла (bundle)

Классический «репитер» из реальной вёрстки конструктора товарных бандлов: группы позиций («И» между собой) → внутри каждой позиции несколько взаимозаменяемых альтернатив («ИЛИ» между собой) → любую альтернативу можно превратить в комбо из нескольких товаров сразу. Добавление товаров — через поиск с $ajax (здесь — с замоканным ответом сервера, как в примере ajax). Каждый динамический атрибут собран в один набор u-bind — причём не только сама привязка, но и вся логика изменения данных: отдельных методов вроде addGroup()/removeProduct() в u-data нет вовсе, каждое действие — короткое выражение прямо в наборе, рядом с элементом, который его вызывает.

Портирование с Alpine.js: две ловушки

1. Каждое чтение вложенного свойства реактивных данных возвращает новую обёртку прокси над тем же объектом, поэтому array.filter(x => x !== item) из Alpine-версии здесь не работает — сравнение объектов циклов между собой всегда ложно. Все удаления ниже — через .splice(index, 1) по индексу, тем же приёмом, что и removeRule(key, index) в примере builder; сама мутация массива на месте, без пересборки, реактивна — см. u-each. Перестановка соседних элементов (moveGroupUpBtn и т. п.) — исключение: своп по двум индексам не входит в список отслеживаемых методов, поэтому там по-прежнему собирается копия и присваивается обратно.

2. Метод $ajax доступен только внутри выражения @событие — обычный метод u-data его не видит (в отличие от глобальной функции ajax() в исходном проекте). Поэтому поиск товаров вызывается прямо в наборе u-bind строкой-выражением, а не отдельным методом searchProduct().

<div u-data="bundle">
  <button type="button" u-bind="addGroupBtn">+ Подгруппа</button>

  <pre u-text="JSON.stringify(groups, null, 2)"></pre>

  <div u-each="(group, gi) in groups" class="bundle-group">
    <div class="bundle-group__header">
      <input type="text" u-bind="groupNameField" placeholder="Подзаголовок группы">
      <button type="button" u-bind="removeGroupBtn">Удалить подгруппу</button>
      <button type="button" u-bind="moveGroupUpBtn">⌃</button>
    </div>

    <div class="bundle-items">
      <div u-each="(item, ii) in group.items" class="bundle-item" data-condition="AND">
        <div class="bundle-item__products">
          <div u-each="(product, pi) in item.products" class="bundle-product" data-condition="OR">
            <span u-bind="productMixBadge">MIX:</span>

            <img u-bind="productImage">
            <input type="checkbox" u-bind="productOptional">
            <input type="text" u-bind="productShortTitle" placeholder="Короткое название">
            <a target="_blank" u-bind="productLink"></a>
            <input type="number" min="1" max="99" u-bind="productQty" required>
            <span u-bind="productPrice"></span>

            <button type="button" u-bind="joinBtn">Комбо</button>
            <button type="button" u-bind="removeProductBtn">×</button>
            <button type="button" u-bind="moveProductUpBtn">⌃</button>
            <button type="button" u-bind="moveItemUpBtn">⌄</button>

            <div class="bundle-mix" u-bind="mixWrapper">
              <div class="bundle-mix__list">
                <div u-each="(mixed, mi) in product.mix">
                  <img u-bind="mixedImage">
                  <input type="checkbox" u-bind="mixedOptional">
                  <input type="text" u-bind="mixedShortTitle">
                  <a target="_blank" u-bind="mixedLink"></a>
                  <input type="number" min="1" max="99" u-bind="mixedQty" required>
                  <span u-bind="mixedPrice"></span>
                  <button type="button" u-bind="removeMixedBtn">×</button>
                </div>
              </div>

              <div class="bundle-search" u-bind="mixSearchWrapper">
                <input type="search" u-bind="mixSearchField" data-include="1,2,3">
                <div u-each="mixedResult in product.search">
                  <button type="button" u-bind="mixedResultBtn">
                    <img u-bind="mixedResultImage">
                    <span u-bind="mixedResultInfo"></span>
                  </button>
                </div>
              </div>
            </div>
          </div>
        </div>

        <div class="bundle-search" u-bind="itemSearchWrapper">
          <input type="search" u-bind="itemSearchField" data-include="1,2,3">
          <div u-each="result in item.search">
            <button type="button" u-bind="resultBtn">
              <img u-bind="resultImage">
              <span u-bind="resultInfo"></span>

          </div>
        </div>

Youla.data('bundle', () => ({
  groups: [],

  // Каждое действие живёт прямо в своём u-bind-наборе — отдельных методов на u-data нет.
  addGroupBtn: {
    '@click': "groups.push({ name: '', items: [{ search: [], products: [] }] })",
  },

  groupNameField: {
    ':value': 'group.name',
    '@input': 'group.name = $el.value',
  },
  removeGroupBtn: {
    '@click': 'groups.splice(gi, 1)',
  },
  moveGroupUpBtn: {
    'u-show': 'gi > 0',
    '@click': `
      const g = [...groups];
      [g[gi - 1], g[gi]] = [g[gi], g[gi - 1]];
      groups = g
    `,
  },
  addItemBtn: {
    '@click': "group.items.push({ search: [], products: [] })",
  },

  itemSearchWrapper: {
    '@click.outside': 'item.search = []',
  },
  itemSearchField: {
    '@focus': "$ajax.get('/bundle/search', { search: $el.value, include: $el.dataset.include }).then(r => item.search = r)",
    '@input.delay.250ms': "$ajax.get('/bundle/search', { search: $el.value, include: $el.dataset.include }).then(r => item.search = r)",
    '@blur': "$el.value = ''",
  },
  resultBtn: {
    '@click': `
      item.products.push({ isOptional: false, shortTitle: '', qty: 1, mix: [], ...result });
      item.search = []
    `,
  },
  resultImage: {
    ':src': 'result.image',
    ':alt': 'result.title',
  },
  resultInfo: {
    'u-html': "result.title + ' — ' + result.price + ' ₽'",
  },

  productImage: {
    ':src': 'product.image',
    ':alt': 'product.title',
    'u-show': '!product.mix.length',
  },
  productOptional: {
    ':checked': 'product.isOptional',
    '@change': 'product.isOptional = $el.checked',
    'u-show': '!product.mix.length',
  },
  productShortTitle: {
    ':value': 'product.shortTitle',
    '@input': 'product.shortTitle = $el.value',
  },
  productLink: {
    ':href': 'product.permalink',
    'u-text': 'product.title',
    'u-show': '!product.mix.length',
  },
  productQty: {
    ':value': 'product.qty',
    '@input': 'product.qty = parseInt($el.value) || 1',
    'u-show': '!product.mix.length',
  },
  productPrice: {
    'u-html': "' × ' + product.price + ' ₽'",
    'u-show': '!product.mix.length',
  },
  productMixBadge: {
    'u-show': 'product.mix.length > 0',
  },
  joinBtn: {
    'u-show': '!product.mix.length',
    '@click': `
      const { mix, search, ...snapshot } = product;
      product.mix = [snapshot];
      product.search = []
    `,
  },
  removeProductBtn: {
    '@click': `
      if (item.products.length === 1) {
        group.items.splice(ii, 1);
      } else {
        item.products.splice(pi, 1);
      }
      if (group.items.length === 0) {
        groups.splice(gi, 1);
      }
    `,
  },
  moveProductUpBtn: {
    'u-show': 'pi > 0',
    '@click': `
      const p = [...item.products];
      [p[pi - 1], p[pi]] = [p[pi], p[pi - 1]];
      item.products = p
    `,
  },
  moveItemUpBtn: {
    'u-show': 'pi === 0 && ii > 0',
    '@click': `
      const it = [...group.items];
      [it[ii - 1], it[ii]] = [it[ii], it[ii - 1]];
      group.items = it
    `,
  },

  mixWrapper: {
    'u-show': 'product.mix.length > 0',
  },
  mixSearchWrapper: {
    '@click.outside': 'product.search = []',
  },
  mixSearchField: {
    '@focus': "$ajax.get('/bundle/search', { search: $el.value, include: $el.dataset.include }).then(r => product.search = r)",
    '@input.delay.250ms': "$ajax.get('/bundle/search', { search: $el.value, include: $el.dataset.include }).then(r => product.search = r)",
    '@blur': "$el.value = ''",
  },
  mixedResultBtn: {
    '@click': `
      product.mix.push({ isOptional: false, shortTitle: '', qty: 1, ...mixedResult });
      product.search = []
    `,
  },
  mixedResultImage: {
    ':src': 'mixedResult.image',
    ':alt': 'mixedResult.title',
  },
  mixedResultInfo: {
    'u-html': "mixedResult.title + ' — ' + mixedResult.price + ' ₽'",
  },

  mixedImage: {
    ':src': 'mixed.image',
    ':alt': 'mixed.title',
  },
  mixedOptional: {
    ':checked': 'mixed.isOptional',
    '@change': 'mixed.isOptional = $el.checked',
  },
  mixedShortTitle: {
    ':value': 'mixed.shortTitle',
    '@input': 'mixed.shortTitle = $el.value',
  },
  mixedLink: {
    ':href': 'mixed.permalink',
    'u-text': 'mixed.title',
  },
  mixedQty: {
    ':value': 'mixed.qty',
    '@input': 'mixed.qty = parseInt($el.value) || 1',
  },
  mixedPrice: {
    'u-html': "' × ' + mixed.price + ' ₽'",
  },
  removeMixedBtn: {
    '@click': 'product.mix.splice(mi, 1)',
  },
}));


  








  Мок-сервер ниже фильтрует каталог по подстроке названия и, если задан data-include,
  ещё и по списку разрешённых ID — так поиск можно ограничить конкретным набором товаров для этой
  секции бандла, не трогая остальной каталог. Задержка ввода перед запросом — модификатор
  .delay.250ms, тот же, что и в событиях.







  Блок с JSON внизу примера — ровно то, что легло бы в тело запроса на сохранение бандла: тот же
  groups, просто выведенный на страницу через u-text
  вместо console.log() из исходного Alpine-варианта.
