Рейтинг звёздами

У каждой из пяти звёзд — три привязки сразу: подсветка при наведении и выборе (:class), запоминание наведённой звезды (@mouseenter) и клик для выбора оценки (@click).

Повторять эту тройку пять раз с разными номерами — такое же дублирование, как в примере v-bind с параметризованными вкладками.

Метод star(n) возвращает набор атрибутов для конкретного номера, а разметка просто подставляет его через v-bind="star(n)". 

document.addEventListener('youla:init', () => {
  Youla.data('rating', () => ({
    value: 3,
    hovered: 0,
    hover(n) {
      this.hovered = n;
    },
    leave() {
      this.hovered = 0;
    },
    rate(n) {
      this.value = n;
    },
    isFilled(n) {
      return n <= (this.hovered || this.value);
    },
    star(n) {
      return {
        ':class': `{ filled: isFilled(${n}) }`,
        '@mouseenter': `hover(${n})`,
        '@click': `rate(${n})`,
      };
    },
  }));
});

<div v-data="rating" @mouseleave="leave()">
  <span v-bind="star(1)" class="star">★</span>
  <span v-bind="star(2)" class="star">★</span>
  <span v-bind="star(3)" class="star">★</span>
  <span v-bind="star(4)" class="star">★</span>
  <span v-bind="star(5)" class="star">★</span>

  <div>Оценка: <span v-text="value"></span> из 5</div>
</div>

Звёзды написаны явно, а не через v-each: их ровно пять, и это фиксированный набор кнопок, а не меняющийся список — v-each здесь только пересчитывал бы один и тот же шаблон без пользы.

star(n) вызывается прямо в разметке с нужным номером, а ${n} подставляется в строки-выражения один раз, при вызове метода.

★ ★ ★ ★ ★
Оценка: из 5

hovered хранит номер звезды под курсором и сбрасывается методом leave(), повешенным на весь компонент, — поэтому подсветка при наведении не зависит от того, над какой именно звездой сейчас курсор.
