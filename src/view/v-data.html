v-data

Директива v-data — стартовая точка в Youla.js. Она превращает элемент HTML в компонент и задаёт его реактивные данные, доступные во всех дочерних выражениях.

Модификаторы

.local и .cookie

Автоматически сохраняют значение свойства в localStorage или cookie и восстанавливают его при следующей загрузке страницы.

Это удобно для пользовательских настроек: темы оформления, языка интерфейса или свёрнутых панелей — того, что должно сохраняться между визитами на сайт.

Те же модификаторы поддерживает и v-prop — используйте их там, если нужно сохранять значение конкретного поля формы.

Что выбрать: .local или .cookie?

Оба модификатора решают одну задачу — данные переживают перезагрузку страницы, — но хранят их в разных местах. От этого и зависит, какой стоит выбрать.

Критерий .local (localStorage) .cookie
Лимит объёма ~5–10 МБ на домен (зависит от браузера) ~4 КБ на одну cookie, обычно не больше 50 cookie на домен
Кто видит данные Только браузер, через JavaScript Браузер и сервер — cookie уезжают с каждым HTTP-запросом на этот домен
Время жизни Пока пользователь сам не очистит хранилище Управляется явно; без указания срока пропадает вместе с закрытием вкладки
Типичное применение Черновик формы, тема оформления, список задач — то, что нужно только интерфейсу Значение, которое должен прочитать сервер: согласие на использование cookie, персонализация при первой отрисовке страницы

Простое правило: по умолчанию берите .local — он вмещает намного больше данных и не увеличивает вес каждого запроса к серверу.

Переключайтесь на .cookie только тогда, когда значение нужно именно серверу — например, чтобы отрисовать нужную версию страницы ещё до загрузки JavaScript.

Cookie уезжают с каждым запросом, поэтому не храните в них ничего объёмного вроде списка задач — оставьте место для короткого флага или идентификатора.

Принять всплывающее окно с файлами cookie

Окно "Мы используем файлы cookie!" будет появляться при каждой перезагрузке страницы. Однако после нажатия кнопки "Ок, принято" Youla.js запомнит выбор пользователя и не будет отображать его. 

<div v-data="{popup: false}">
  <div v-prop.cookie="popup" v-show="!popup" hidden>
    <span>We use cookie!</span>
    <button type="button" @click="popup = !popup">Ок, принято</button>
  </div>
  <p v-show="popup">
    Модальное окно уже было показано
  </p>
</div>

    <button type="button" @click="--voices; voted = true" :disabled="voted">
      <i class="ph ph-thumbs-down"></i>
    </button>
    <span v-text="voices"></span>
    <button type="button" @click="++voices; voted = true" :disabled="voted">
      <i class="ph ph-thumbs-up"></i>
    </button>
    <span class="hidden" @click="voices = 1000; voted = false" v-show="voted">Reset</span>
  </div>
</div>
