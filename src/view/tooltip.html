Тултипы (v-tooltip)

Директива v-tooltip показывает всплывающую подсказку у любого элемента — без сборки, без сторонней библиотеки. Содержимое берётся из значения атрибута, позиция и способ показа — из модификаторов, например v-tooltip.left.click. Директива работает на любом элементе: div, span, p, a, button, input, img — без каких-либо допущений об интерактивности элемента.

Базовый пример

Без модификаторов используется поведение по умолчанию: наведение курсора (hover) и подсказка сверху (top). 

<div v-tooltip="'Простая подсказка'" class="tooltip-anchor">
  Наведите курсор
</div>
Наведите курсор

HTML в содержимом

Значение директивы вставляется как настоящий HTML — так же, как в v-html, без экранирования и очистки: разметка внутри подсказки должна быть доверенной. 

<div v-tooltip="'<strong>Заголовок</strong><br><span>Описание</span>'" class="tooltip-anchor">
  Подсказка с разметкой
</div>

Позиционирование

Модификаторы .top, .bottom, .left, .right и .auto задают, с какой стороны элемента появится подсказка. auto сам выбирает сторону с наибольшим свободным местом — и пересчитывает её при скролле и ресайзе, пока подсказка открыта. 

<div v-tooltip.top="'Сверху'" class="tooltip-anchor">top</div>
<div v-tooltip.bottom="'Снизу'" class="tooltip-anchor">bottom</div>
<div v-tooltip.left="'Слева'" class="tooltip-anchor">left</div>
<div v-tooltip.right="'Справа'" class="tooltip-anchor">right</div>
<div v-tooltip.auto="'Авто'" class="tooltip-anchor">auto</div>

Триггеры

.hover (по умолчанию) показывает подсказку при наведении и фокусе, скрывает — при уходе курсора или потере фокуса. .click переключает подсказку по клику и дополнительно закрывается по клику снаружи и по клавише Escape. .focus показывает подсказку только по фокусу, полностью игнорируя наведение курсора мышью — удобно для подсказки-подтверждения у поля ввода, которая не должна появляться просто от наведения на форму.

На тач-устройствах у .hover нет наведения — подсказка появляется по тапу и, как и .click, закрывается по тапу снаружи, так как отпускания пальца без «увода курсора» не существует. 

<div v-tooltip.hover="'Показывается по наведению'" class="tooltip-anchor">hover</div>
<button type="button" v-tooltip.click="'Показывается по клику'" class="tooltip-anchor">click</button>
<input v-tooltip.focus="'Показывается только по фокусу'" placeholder="focus" class="tooltip-anchor">
hover

Комбинации модификаторов

Модификаторы позиции и триггера независимы и свободно сочетаются друг с другом. 

<div v-tooltip.top.hover="'...'"></div>
<div v-tooltip.bottom.click="'...'"></div>
<div v-tooltip.left.hover="'...'"></div>
<div v-tooltip.right.click="'...'"></div>
<div v-tooltip.auto.hover="'...'"></div>

Разные элементы

Директива не делает никаких допущений о цели — она одинаково работает на блочных, строчных, интерактивных и неинтерактивных элементах, не добавляя им tabindex или роль, которых там не было. 

<div v-tooltip="'Подсказка на div'">div</div>
<span v-tooltip="'Подсказка на span'">span</span>
<p v-tooltip="'Подсказка на p'">p</p>
<a href="#" v-tooltip="'Подсказка на a'">a</a>
<button type="button" v-tooltip="'Подсказка на button'">button</button>
<input placeholder="input" v-tooltip="'Подсказка на input'">
<img src="..." v-tooltip="'Подсказка на img'">

Особые случаи

Длинный или многострочный текст переносится по ширине ограниченной подсказки, а не растягивает её в одну строку через весь экран. 

<div v-tooltip="'Очень длинный текст подсказки, который не помещается в одну строку и должен
корректно переноситься внутри ограниченной по ширине подсказки, не растягиваясь на весь экран.'">
  Длинная подсказка
</div>
Длинная подсказка

Динамическое содержимое

Значение директивы — обычное реактивное выражение: подсказка обновляется вслед за данными компонента, а сама её DOM-нода при этом не пересоздаётся. 

<div v-data="{ count: 0 }">
  <button type="button" @click="count++" v-tooltip="`Кликов: ${count}`">
    Наведите после клика
  </button>
</div>
