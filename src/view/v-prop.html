v-prop

Директива v-prop связывает поле формы — input, select или textarea — с данными компонента v-data одним атрибутом, без ручного объявления значения и обработчика ввода.

Меньше кода. Без v-prop значение пришлось бы объявлять дважды — атрибутом value/checked в разметке и ключом в v-data.

А затем вручную вешать @input/@change, который читает $el.value (или $el.checked, выбранные <option> — по-своему для каждого типа поля) и пишет это в данные. Сравните два одинаковых по смыслу подхода: 

<form v-data>
  <input type="text" value="Hello" v-prop="test">
  <span v-text="test"></span>
</form>
 
<form v-data="{test: 'Hello'}">
  <input type="text" value="Hello" @keydown.delay.1ms="test = $el.value">
  <span v-text="test"></span>
</form>

Во втором случае не требуется объявления в директиве v-data и события ввода.

Мерцание при загрузке. v-prop считывает значение поля прямо из уже отрисованной разметки при инициализации компонента — до того, как данные становятся реактивными.

Поэтому состояние в v-data сразу совпадает с тем, что видно на экране. При ручном подходе значение и атрибут value объявлены отдельно: стоит им разойтись — и зависящая от них разметка на первом кадре покажет неверное значение.

Разные типы полей. Чекбоксы, радиокнопки и select по-разному хранят своё значение в DOM. v-prop сам определяет тип поля и обрабатывает его — писать отдельную логику синхронизации для каждого вида не нужно.

Модификаторы .number и .trim берут на себя приведение типов и очистку пробелов, а .local/.cookie — сохранение значения между перезагрузками страницы.

Модификаторы

.number

По умолчанию v-prop хранит значение поля как строку. Добавьте модификатор .number, чтобы Youla.js приводила его к числу. 

<form v-data>
  <input type="text" value="10" v-prop.number="age">
  <div>Значение: <span v-text="age"></span>, тип: <span v-text="typeof age"></span></div>
</form>

.trim

Убирает пробелы в начале и конце введённого значения — полезно для полей вроде email или логина, где лишние пробелы мешают. В примере ниже пробел обрезается при каждом нажатии клавиши. 

<form v-data>
  <input type="text" v-prop.trim="name">
  <div v-text="name"></div>
</form>

Если пробелы нужно убирать только после завершения ввода, добавьте модификатор .lazy. 

<form v-data>
  <input type="text" v-prop.lazy.trim="name">
  <div v-text="name"></div>
</form>

.local и .cookie

Сохраняют значение поля в localStorage или куках и восстанавливают его при следующей загрузке страницы — удобно для пользовательских настроек, например темы оформления.

Чем local storage и куки отличаются по объёму и назначению и как выбрать между ними — на странице v-data. 

<form v-data>
  <div>Сохранение в local storage</div>
  <input type="text" v-prop.local="firstName">
  <div v-text="firstName"></div>
  <br>
  <div>Сохранение в куках</div>
  <input type="text" v-prop.cookie="lastName">
  <div v-text="lastName"></div>
</form>
