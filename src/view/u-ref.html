u-ref

Атрибут u-ref именует элемент, чтобы затем обратиться к нему напрямую через $refs внутри выражения обработчика события — без document.querySelector и без хранения ссылки на элемент в данных компонента.

В отличие от директив вроде u-show или u-text, значение u-ref не вычисляется как JS-выражение — это обычная строка-имя, под которым элемент становится доступен в $refs. 

<div u-data>
  <input u-ref="email" type="email" placeholder="you@example.com">
  <button @click="$refs.email.focus()">Перейти к полю</button>
</div>

Нажатие на кнопку вызывает $refs.email — DOM-элемент с атрибутом u-ref="email" — и сразу передаёт ему .focus(), как обычному элементу, полученному через querySelector.

$refs доступен в любом выражении

$refs, как и $el, $event и $root, доступен в любом выражении — не только в @событие, но и в значении u-text, u-show, :class и других директив (подробнее — на странице Полный синтаксис). Внутри метода, вызванного из выражения (как highlight() ниже), эти переменные доступны через this.$refs, this.$el и так далее — без явной передачи аргументом.

Сам атрибут u-ref при этом можно писать на одном элементе вместе с любой другой директивой — он ничего не меняет в её работе, просто добавляет элементу имя: 

<div u-text="label" u-ref="labelEl"></div>
<button @click="console.log($refs.labelEl)">Показать элемент в консоли</button>

Динамические имена через u-bind

Внутри u-bind ключ 'u-ref' работает так же, как и написанный прямо в разметке, но его значение можно вычислить — например, дать каждому элементу цикла u-each своё уникальное имя. 

<ul u-data="taskList">
  <li u-each="task in tasks" u-bind="row(task)">
    <span u-text="task.title"></span>
  </li>

  <button @click="highlight(2)">Показать вторую задачу</button>
</ul>

Youla.data('taskList', () => ({
  tasks: [
    { id: 1, title: 'Написать отчёт' },
    { id: 2, title: 'Проверить почту' },
  ],

  row(task) {
    return {
      'u-ref': `task-${task.id}`,
    }
  },

  highlight(id) {
    this.$refs[`task-${id}`].scrollIntoView({ behavior: 'smooth' });
  },
}))

highlight() обращается к this.$refs напрямую, поэтому click-выражение теперь просто highlight(2) — без передачи $refs аргументом. this внутри метода — те же реактивные данные компонента (tasks, row, highlight), что и в любом другом методе u-data, только с $el, $event, $refs и $root поверх них.

Один компонент — одна область видимости

$refs ищет элемент только внутри текущего компонента: если внутри него вложен ещё один элемент с собственным u-data, его u-ref-элементы в $refs родителя не попадают — так каждый компонент случайно не задевает разметку другого.

Если на странице повторить одно и то же имя u-ref на нескольких элементах одного компонента, $refs вернёт первый найденный при обходе DOM — держите имена уникальными в пределах компонента, как обычные переменные.
