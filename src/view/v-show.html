v-show

Директива v-show управляет видимостью элемента с помощью свойства display. В отличие от условных директив, которые добавляют и удаляют элемент из DOM, v-show оставляет его в разметке всегда, лишь переключая display: none. Это делает переключение мгновенным — элемент не нужно создавать заново и повторно инициализировать. 

<div v-data="{ open: false }">
  <button @click="open = ! open">Переключить</button>

  <div v-show="open">
    Контент...
  </div>
</div>

При нажатии кнопки "Переключить" блок будет отображаться и скрываться соответствующим образом.

Любое выражение вместо простого флага

В v-show можно передать любое выражение, а не только имя булевой переменной — оно будет вычислено и приведено к true/false при каждом обновлении данных. 

<div v-data="{ cart: ['Book', 'Pen'] }">
  <button @click="cart = [...cart, 'Book']">Добавить в корзину</button>
  <button @click="cart = []">Очистить корзину</button>

  <p v-show="cart.length > 0">Товаров в корзине: <strong v-text="cart.length"></strong></p>
  <p v-show="cart.length === 0">Корзина пуста</p>
</div>

Переключение вкладок

Одна переменная может управлять сразу несколькими блоками v-show, что удобно для реализации вкладок, аккордеонов и похожих интерфейсов. 

<div v-data="{ tab: 'profile' }">
  <button @click="tab = 'profile'">Профиль</button>
  <button @click="tab = 'settings'">Настройки</button>

  <div v-show="tab === 'profile'">Здесь данные профиля.</div>
  <div v-show="tab === 'settings'">Здесь настройки аккаунта.</div>
</div>

Значение display после показа элемента

v-show всегда возвращает видимому элементу display: block, потому что задаёт его напрямую через el.style.display. Если элемент должен становиться inline, flex или grid, обычное css-правило по классу его не переопределит — инлайн-стиль всегда имеет приоритет. Добавьте !important к нужному правилу, чтобы вернуть желаемое значение display.

Если состояние v-show при загрузке страницы "по умолчанию" равно "false", вы можете захотеть использовать глобальный атрибут hidden, чтобы избежать "мерцания страницы" (эффекта, который возникает, когда браузер отображает ваш контент до того, как Youla.js завершит его инициализацию и скрытие).

Однако, чтобы hidden работал, вы должны добавить на страницу следующий CSS-код.

    [hidden] { display: none !important; }
