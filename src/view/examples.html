На этой странице — примеры, где несколько директив Youla.js работают вместе: v-data, v-text, v-html, v-show, v-prop, v-each и v-bind, а также события и атрибуты. Каждый пример решает конкретную практическую задачу.

Форма с разными типами полей

Один и тот же атрибут v-prop связывает данные с любым типом поля — текстовым, числовым, чекбоксом, select или textarea. Ниже собраны все варианты в одной форме. 

<div v-data="{
  signIn: '', inputo: 10, singlet: true, colors: ['Красный', 'Жёлтый'],
  select: '', multiple: [], answer: '', content: 'Всё работает!'
}">
  <label>Логин</label>
  <input v-prop="signIn" type="text">
  <div v-text="signIn"></div>

  <label>Количество (от 8 до 12)</label>
  <input v-prop="inputo" :type="'number'" :min="8" :max="12">
  <div v-text="inputo"></div>

  <label>
    <input type="checkbox" v-prop="singlet"> Согласен получать рассылку
  </label>
  <div v-text="singlet"></div>

  <label>Любимые цвета</label>
  <label><input type="checkbox" value="Красный" v-prop="colors"> Красный</label>
  <label><input type="checkbox" value="Оранжевый" v-prop="colors"> Оранжевый</label>
  <label><input type="checkbox" value="Жёлтый" v-prop="colors"> Жёлтый</label>
  <div v-text="colors"></div>

  <label>Размер</label>
  <select v-prop="select">
    <option value="">Выберите размер</option>
    <option value="Маленький">Маленький</option>
    <option value="Средний">Средний</option>
    <option value="Большой">Большой</option>
  </select>
  <div v-text="select"></div>

  <label>Категории (можно несколько)</label>
  <select multiple v-prop="multiple">
    <option value="Электроника">Электроника</option>
    <option value="Одежда">Одежда</option>
    <option value="Книги">Книги</option>
  </select>
  <div v-text="multiple"></div>

  <label>Вам всё понравилось?</label>
  <label><input type="radio" value="yes" v-prop="answer"> Да</label>
  <label><input type="radio" value="no" v-prop="answer"> Нет</label>
  <div v-text="answer"></div>

  <label>Комментарий</label>
  <textarea v-prop="content"></textarea>
  <div v-text="content"></div>
</div>

Загрузка файла с индикатором прогресса

Третий аргумент $ajax — колбэк прогресса — удобно совмещать с элементом <progress>, который реактивно обновляется по мере отправки файла на сервер. Подробнее о $ajax, его действиях над фрагментами страницы и обработке ответов — на странице Ajax и фрагменты. 

<div v-data="{ percent: 0, items: [] }">
  <form @submit.prevent="$ajax('https://jsonplaceholder.typicode.com/posts', {}, p => percent = p.percent)">
    <input type="file" name="file">
    <button type="submit">Загрузить</button>
    <progress :value="percent" max="100"></progress>
  </form>

  <button type="button" @click.delay.1000ms.once="$ajax('https://jsonplaceholder.typicode.com/posts').then(response => items = response)">
    Показать список постов (загрузится один раз, через секунду)
  </button>
  <ul>
    <li v-each="item in items">
      <span v-text="item.id"></span>: <span v-text="item.title"></span>
    </li>
  </ul>
</div>

v-text, v-html и доступ к элементу через $refs

Пример показывает разницу между v-text и v-html, а также обращение к DOM-элементу по имени, заданному атрибутом v-ref, прямо из обработчика клика на кнопке. 

<div v-data="{ label: 'Обычный текст', markup: '<strong>HTML-разметка</strong>' }">
  <div v-text="label" v-ref="labelEl"></div>
  <div v-html="markup"></div>
  <button @click="console.log($refs.labelEl)">Показать элемент в консоли</button>
</div>

Управляемое поле и счётчик с условным показом

Кнопка может менять значение поля напрямую, а v-show — показывать подсказку только при выполнении условия, без лишних проверок и дублирования логики в разметке. 

<div v-data="{ friends: 'Привет, друг!', count: 2 }">
  <input v-prop="friends">
  <button @click="friends = 'Привет, мир!'">Заменить текст</button>

  <button @click="count--">-</button>
  <span v-text="count"></span>
  <button @click="count++">+</button>
  <div v-show="count > 2">Значение больше двух</div>
</div>

Выпадающее меню с закрытием по клику вне его

Модификатор .outside у @click закрывает меню при клике в любом другом месте страницы — частая задача для выпадающих меню, поповеров и всплывающих подсказок. 

<div v-data="{ open: false }">
  <button @click="open = true">Открыть меню</button>
  <ul :class="{ hidden: !open }" @click.outside="open = false">
    <li>Пункт 1</li>
    <li>Пункт 2</li>
  </ul>
</div>

Особые события: load, intersect и порядок обработчиков

Помимо обычных событий браузера Youla.js поддерживает @load (срабатывает при инициализации элемента) и @intersect (элемент появился в области видимости). Модификатор .capture меняет порядок срабатывания обработчиков на вложенных элементах. 

<div @load="console.log('Элемент инициализирован')"></div>
<div @intersect="console.log('Появился в области видимости')">Прокрутите до сюда</div>
<div @intersect.once="console.log('Появился, сработает только один раз')">И до сюда</div>

<div @click.capture="console.log('Сработает первым')">
  <button @click="console.log('Сработает вторым')">Нажми меня</button>
</div>

Youla.data: усложняем задачу, упрощаем разметку

Пока состояние компонента — пара плоских свойств, объектный литерал прямо в атрибуте v-data="{...}" остаётся самым коротким и понятным путём, как в примерах выше.

Но как только в задаче появляется повторяющаяся логика — проверка границ значения, сравнение с активной вкладкой, фильтрация списка — расписывать её в каждом выражении становится многословно и хрупко.

Одна и та же проверка дублируется в нескольких атрибутах, а любое изменение поведения приходится аккуратно повторять во всех местах, где она встречается.

Youla.data(имя, callback) решает это иначе: даёт компоненту имя и переносит всю повторяющуюся логику в обычный JS-объект с методами, вызываемыми из разметки.

Разметка получает только короткие вызовы вроде increment() или isActive('profile'), а вся логика проверок остаётся в одном месте, в JS-файле компонента.

Такую регистрацию нужно выполнить раньше, чем Youla.js начнёт разбирать страницу, поэтому вызов оборачивают в событие youla:init, которое библиотека создаёт в самом начале своей работы: 

document.addEventListener('youla:init', () => {
  Youla.data('имя', () => ({
    // свойства и методы компонента
  }));
});

В разметке компонент подключается по имени точно так же, как обычный объект: атрибуту v-data достаточно передать строку с именем, без фигурных скобок. 

<div v-data="имя">...</div>

Счётчик с ограничениями

Простой count++/count-- из примера выше отлично работает, пока не нужно ограничивать значение конкретным диапазоном или проверять его перед изменением.

Как только появляются границы и шаг изменения, писать проверку в @click для каждой кнопки, а потом ещё раз в :disabled — становится избыточно и легко забыть.

increment()/decrement() убирают это дублирование: границы и шаг хранятся в данных компонента один раз, и методы сами следят, чтобы значение их не нарушало. 

document.addEventListener('youla:init', () => {
  Youla.data('counter', () => ({
    min: 0,
    max: 5,
    step: 1,
    value: 0,
    increment() {
      this.value = Math.min(this.value + this.step, this.max);
    },
    decrement() {
      this.value = Math.max(this.value - this.step, this.min);
    },
  }));
});

<div v-data="counter">
  <button type="button" @click="decrement()" :disabled="value <= min">−</button>
  <span v-text="value"></span> / <span v-text="max"></span>
  <button type="button" @click="increment()" :disabled="value >= max">+</button>
</div>
