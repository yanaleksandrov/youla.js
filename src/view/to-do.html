Список задач

Список TODO - типовой сценарий, который нужен в любом трекере задач. Список также переживает перезагрузку страницы — задачи сохраняются в браузере автоматически. Ниже — весь код, который для этого нужен. 

document.addEventListener('youla:init', () => {
  Youla.data('todo', () => ({
    value: '',
    tasks: [],
    adder: {
      '@click': "tasks = [...tasks, {title: value, checked: false}]; value = ''",
      ':disabled': '!value.trim()',
    },
    field: {
      '@keydown.enter': "value.trim() && (tasks = [...tasks, {title: value, checked: false}], value = '')",
    },
    checkbox: {
      '@change': 'task.checked = !task.checked',
      ':checked': 'task.checked',
    },
    status: {
      'v-text': 'task.title',
      ':class': "task.checked && 'strike'",
    },
    remover: {
      '@click': 'tasks = tasks.filter((_, i) => i != index)',
    },
    clearer: {
      '@click': 'tasks = []',
    },
  }));
});

<div v-data.local="todo">
  <p>Добавить задачу:</p>
  <input placeholder="Введите новую задачу..." v-prop="value" v-bind="field" />
  <button type="button" v-bind="adder">Добавить</button>

  <div v-show="tasks.length" hidden>
    <p>Список задач:</p>
    <ul>
      <li v-each="(task, index) in tasks">
        <label>
          <input type="checkbox" v-bind="checkbox"> <span v-bind="status"></span>
        </label>
        <button v-bind="remover">Удалить</button>
      </li>
    </ul>
    <button v-bind="clearer">Очистить всё</button>
  </div>
</div>

За сохранение списка между перезагрузками отвечает модификатор .local в v-data.local="todo": он пишет данные компонента в localStorage при каждом изменении и подставляет их обратно при следующей загрузке страницы поверх начальных значений из Youla.data. Если вместо этого нужны куки — например, чтобы список был доступен серверу — замените модификатор на .cookie; если персистентность не нужна вовсе, просто уберите модификатор и оставьте обычный v-data="todo".
