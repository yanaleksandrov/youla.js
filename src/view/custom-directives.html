Пользовательские директивы

Помимо встроенных v-* директив Youla.js позволяет зарегистрировать свои через Youla.directive(). Как устроена регистрация и что получает callback — на странице Extending. Ниже — примеры уже готовых директив из библиотеки.

v-noautofill: блокируем автозаполнение браузера

Атрибут autocomplete="off" браузеры нередко игнорируют, особенно для полей логина и пароля. Директива v-noautofill решает это иначе: делает поле readonly до первого фокуса, из-за чего браузер не успевает предложить сохранённые значения, а сразу после фокуса атрибут снимается и поле ведёт себя как обычное. 

<input type="text" placeholder="Логин" v-noautofill>

Значение директивы не используется — атрибут v-noautofill просто включает поведение, а сама привязка значения поля, как обычно, остаётся за v-prop.

v-highlight: разметка для подсветки синтаксиса

Директива сама не красит текст — она готовит разметку под подсветчик вроде Prism.js: оборачивает содержимое элемента в <code class="language-имя">, добавляет класс line-numbers и выставляет атрибут data-lang. Дальше за подсветку и нумерацию строк отвечает уже сама библиотека — её CSS и JS в этот проект не подключены.

Язык берётся из модификатора — v-highlight.js даёт класс language-js, без модификатора используется language-html. 

<pre v-highlight.js>
Youla.data('user', () => ({
  name: 'Youla.js',
}));
</pre>

v-listen: плеер по клику для аудио

Директива превращает элемент с атрибутом data-src в аудиоплеер: добавляет иконку, скрытый <audio> и по клику переключает воспроизведение. Прогресс проигрывания рисуется прямо на фоне элемента заливкой-градиентом, а data-start/data-end ограничивают проигрываемый отрезок файла вместо всей записи.

Директива активируется только при истинном значении — v-listen="false" оставит элемент обычным текстом, без плеера. 

<span v-listen="true" data-src="/sounds/click.mp3" data-start="0.5" data-end="1.5">
  Прослушать
</span>
Прослушать сигнал

Демо-плеер выше играет короткий тестовый сигнал, сгенерированный прямо в браузере — реальный проект вместо этого укажет обычный путь к аудиофайлу в data-src.

v-collapse: плавное раскрытие и скрытие

Директива анимирует высоту, отступы и поля элемента между 0 и его естественным размером — раскрывает при истинном значении, закрывает при ложном. Никакого CSS-класса не требуется, поведением управляет само выражение атрибута. 

<div v-data="{ open: true }">
  <button type="button" @click="open = !open">Переключить</button>
  <div v-collapse="open">Содержимое, которое плавно раскрывается и закрывается.</div>
</div>
Содержимое, которое плавно раскрывается и закрывается.

v-textarea: автовысота при вводе

Поле растёт по мере набора текста, подстраиваясь под содержимое, — и перестаёт расти после значения-лимита в строках, дальше внутри появляется обычная прокрутка.

Минимальная высота задаётся обычным HTML-атрибутом rows — сама директива его не трогает, это стандартное поведение <textarea>. Максимум строк, до которого можно вырасти, передаётся значением директивы, например v-textarea="6"; без значения используется лимит по умолчанию (99 строк). 

<textarea v-textarea="6" rows="2"></textarea>

v-select: адаптер для SlimSelect

Директива превращает <option>ы (вместе с data-image, data-icon, data-description) и группы <optgroup> в формат данных SlimSelect, а значение атрибута, если оно задано, разбирается как JSON и добавляется в настройки библиотеки. 

<select v-select multiple>
  <option value="js">JavaScript</option>
  <option value="ts">TypeScript</option>
  <option value="py">Python</option>
</select>

SlimSelect в этом проекте не подключён, поэтому демо выше — обычный нативный <select>: директива честно ловит ошибку и оставляет элемент рабочим как есть. С подключённой библиотекой он превратится в стилизованный список с поиском и картинками/иконками у каждого пункта.

v-sticky: прилипающая колонка

Элемент со свойством position: relative у родителя остаётся на месте, пока родитель прокручивается мимо, — не просто «прилипает» к вьюпорту, а остаётся в пределах родителя: колонка выше вьюпорта прокручивается внутри себя, а не съезжает за верх или низ экрана. 

<div style="position: relative; display: flex; gap: 1rem;">
  <div v-sticky>Слежу за колонкой</div>
  <div>Длинная колонка содержимого...</div>
</div>

Youla.js остаётся крошечной библиотекой — около 16kB, без сборки и виртуального DOM.

Реактивность строится на прокси над обычным объектом данных, без своего диалекта шаблонов.

Директивы читаются прямо из атрибутов разметки: v-*, :attribute, @event.

Пользовательские директивы и методы регистрируются через Youla.directive() и Youla.method().

Эта колонка — просто заполнитель, чтобы страница стала достаточно длинной для прокрутки.

Прокрутите чуть ниже и обратно — левая колонка должна остаться на виду всё это время.

v-step: пошаговый мастер

v-step="условие" отмечает завершённость шага по значению выражения; метод $step (свой на каждый корневой компонент) отвечает за переходы — $step.goNext(), $step.goBack() и read-only проверки вроде $step.canGoNext(). Видимость шагов директива переключает напрямую через el.style.display, а не через v-show — методы Youla.method(), как и $step, доступны только внутри выражений событий (@click и подобных), а не внутри v-show/:attribute. Подробнее об этом различии — на странице Extending.

Раз кнопка «Далее» не может реактивно отключаться сама по себе, проверку встраивают прямо в её обработчик — @click="$step.canGoNext() && $step.goNext()" — переход просто не случится, пока шаг не завершён. 

<div v-data="{ name: '', email: '' }">
  <div v-step="name.trim().length > 0">
    <input v-prop="name" placeholder="Ваше имя">
  </div>
  <div v-step="/.+@.+\..+/.test(email)">
    <input v-prop="email" placeholder="you@example.com">
  </div>
  <div v-step="true">
    <p>Готово! Оба шага пройдены.</p>
  </div>
  <button type="button" @click="$step.goBack()">Назад</button>
  <button type="button" @click="$step.canGoNext() && $step.goNext()">Далее</button>
</div>

Готово! Оба шага пройдены.
