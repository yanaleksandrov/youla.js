v-html

Директива v-html позволяет вставлять HTML-код в элемент, заменяя его текущее содержимое. Это аналог свойства innerHTML в JavaScript.

⚠️ Опасность XSS

Используйте только для доверенного контента и никогда - для контента, предоставленного пользователем. Динамический рендеринг HTML третьими лицами может легко привести к уязвимостям XSS.

Вот простой пример использования v-html для отображения имени пользователя:

<div v-data="{ username: '<strong>Yan Aleksandrov</strong>' }">
  Имя: <span v-html="username"></span>
</div>

Живой предпросмотр

v-html реактивен, как и любая другая директива: содержимое элемента перерисовывается при каждом изменении связанных данных. Это удобно, например, для предпросмотра форматированного текста прямо во время ввода. 

<div v-data="{ markup: '<strong>Привет!</strong> Это <em>живой</em> предпросмотр.' }">
  <textarea v-prop="markup"></textarea>
  <div v-html="markup"></div>
</div>

Любое выражение вместо простой переменной

В v-html, как и в другие директивы, можно передать произвольное выражение — например, собрать разметку из нескольких полей объекта прямо на месте. 

<div v-data="{
  product: { name: 'Наушники', price: 4990, inStock: true }
}">
  <div v-html="`
    <strong>${product.name}</strong>
    <span style='color:${product.inStock ? 'green' : 'crimson'}'>
      ${product.inStock ? 'В наличии' : 'Нет в наличии'}
    </span> — ${product.price} ₽
  `"></div>
</div>

Вложенные директивы Youla.js не обрабатываются

v-html лишь вставляет строку через innerHTML — он не запускает повторную инициализацию компонента для нового содержимого. Если вставленная строка содержит атрибуты вроде v-text или v-each, они останутся в разметке как есть, никак не вычисляясь: ниже вы увидите буквальный текст {{ user.name }}, а не имя пользователя. 

<div v-data="{ user: { name: 'Ian' } }">
  <div v-html="`<span v-text='user.name'>{{ user.name }}</span>`"></div>
</div>

Если вставленный фрагмент должен быть по-настоящему интерактивным, оберните его в собственный элемент с атрибутом v-data — Youla.js подхватит его отдельно и проинициализирует как самостоятельный компонент, как только он появится в DOM.

<%= _.template(require('./parts/footer.html').default)(data) %>
