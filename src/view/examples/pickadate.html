Календарь (u-pickadate)

Директива u-pickadate — реактивная обёртка над AirDatepicker: превращает любой элемент (обычно <input>) во всплывающий календарь. Библиотека подключена в проект напрямую, отдельно её загружать не нужно.

В отличие от u-select, значение директивы — не JSON, а обычное JS-выражение с доступом к данным компонента, как у любой другой директивы. Стоит измениться данным, от которых оно зависит, — и календарь пересоздаётся с новыми опциями, поэтому в него можно передавать переменные, а не только статические значения.

Опции вкратце

Опция Описание По умолчанию
range Выбор диапазона: первый клик — начало, второй — конец. false
multipleDates Несколько независимых дат сразу; число ограничивает их количество, true — без лимита. false
minDate, maxDate Границы допустимых дат — за ними навигация по календарю блокируется. false (без границ)
dateFormat Формат даты в поле — строка ('yyyy-MM-dd') или функция (date) => string. 'yyyy-MM-dd'
view, minView Стартовый экран ('days'/'months'/'years') и самый детальный экран, до которого можно углубиться. 'days'
autoClose Закрывать календарь сразу после выбора даты (в диапазоне — после выбора обеих). false
onSelect Коллбэк ({date, formattedDate}) => void, вызывается при каждом выборе. null

Базовая дата

<input type="text" u-pickadate="{ autoClose: true }" placeholder="Выберите дату">

Диапазон дат: бронирование номера

range: true превращает одиночный выбор в диапазон: первый клик отмечает заезд, второй — выезд, между ними подсвечивается весь диапазон. minDate запрещает выбрать прошедшую дату. 

<input
  type="text"
  u-pickadate="{ range: true, autoClose: true, minDate: new Date() }"
  placeholder="Заезд — выезд"
>

Несколько дат: смены на неделю

multipleDates с числом ограничивает, сколько независимых дат можно отметить — здесь не больше 3 смен. 

<input type="text" u-pickadate="{ multipleDates: 3 }" placeholder="До 3 дат">

Реактивные опции: переключение диапазона

Опции — обычное выражение, не JSON, поэтому в них можно подставлять данные компонента. Переключите чекбокс — календарь пересоздастся уже в режиме диапазона, без единой строчки собственного JS для этого перехода. 

<div u-data="{ isRange: false }">
  <label>
    <input type="checkbox" u-prop="isRange"> Диапазон дат
  </label>
  <input type="text" u-pickadate="{ range: isRange, autoClose: true }" placeholder="Дата">
</div>

onSelect: выбранная дата в интерфейсе

onSelect получает и «сырую» дату, и уже отформатированную строку — здесь она просто выводится рядом с полем через u-text.

Выбрано: 

<div u-data="{ picked: '' }">
  <input
    type="text"
    u-pickadate="{ autoClose: true, onSelect: ({ formattedDate }) => picked = formattedDate }"
    placeholder="Выберите дату"
  >
  <p>Выбрано: <strong u-text="picked || '—'"></strong></p>
</div>

Локаль, первый день недели и формат даты можно один раз задать для всего сайта через window.expansa.datepicker/weekStart/dateFormat — любой u-pickadate без своих значений этих опций подхватит их автоматически.
