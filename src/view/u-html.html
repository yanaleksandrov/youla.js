u-html

Директива u-html вставляет HTML-код в элемент, заменяя его текущее содержимое — это аналог свойства innerHTML в обычном JavaScript, но с реактивным обновлением.

⚠️ Опасность XSS

Используйте только для доверенного контента и никогда — для контента, предоставленного пользователем. Динамический рендеринг HTML третьими лицами может легко привести к уязвимостям XSS.

Вот простой пример использования u-html для отображения имени пользователя вместе с HTML-тегом форматирования, вставленным прямо в значение этого свойства.

Имя: 
<div u-data="{ username: '<strong>Yan Aleksandrov</strong>' }">
  Имя: <span u-html="username"></span>
</div>

Живой предпросмотр

u-html реактивен, как и любая другая директива: содержимое элемента перерисовывается при каждом изменении связанных данных. Это удобно, например, для предпросмотра форматированного текста прямо во время ввода. 

<div u-data="{ markup: '<strong>Привет!</strong> Это <em>живой</em> предпросмотр.' }">
  <textarea u-prop="markup"></textarea>
  <div u-html="markup"></div>
</div>

⚠️ Пока значение markup нигде не сохраняется и не показывается другим людям, этот предпросмотр безопасен — пользователь выполняет свой же HTML в своей же вкладке. Но если такое же поле потом уходит на бэкенд и оттуда рендерится для других посетителей (например, черновик комментария) — это уже полноценный сохранённый XSS.

Любое выражение вместо простой переменной

В u-html, как и в другие директивы, можно передать произвольное выражение — например, собрать разметку из нескольких полей объекта прямо в шаблоне страницы. 

<div u-data="{
  product: { name: 'Наушники', price: 4990, inStock: true }
}">
  <div u-html="`
    <strong>${product.name}</strong>
    <span style='color:${product.inStock ? 'green' : 'crimson'}'>
      ${product.inStock ? 'В наличии' : 'Нет в наличии'}
    </span> — ${product.price} ₽
  `"></div>
</div>
