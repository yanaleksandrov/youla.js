Загрузчик аватарки

Форме профиля обычно нужен загрузчик фото: показать превью сразу после выбора файла, до отправки на сервер, и чем-то заменить пустое место, пока файл не выбран — обычно инициалами пользователя. 

<div class="demo example-avatar" u-data="avatar">
  <div class="avatar-circle" u-bind="picture">
    <span u-bind="initials" hidden></span>
  </div>

  <input type="text" placeholder="Введите имя" u-bind="field">

  <input type="file" accept="image/*" u-bind="uploader">

  <button type="button" u-bind="remover" hidden>Удалить</button>
</div>

Youla.data('avatar', () => ({
  name: '',
  image: '',
  field: {
    'u-prop': 'name',
  },
  picture: {
    ':title': 'name',
    ':style': "image && `background-image:url(${image})`",
  },
  initials: {
    'u-show': '!image',
    'u-text'() {
      return this.name.trim().split(/\s+/).map(word => word[0]).slice(0, 2).join('').toUpperCase();
    },
  },
  uploader: {
    '@change'() {
      let file = this.$event.target.files[0];
      if (file) {
        let reader = new FileReader();
        reader.onload = e => this.image = e.target.result;
        reader.readAsDataURL(file);
      }
    },
  },
  remover: {
    'u-show': 'image',
    '@click'() {
      let input = this.$root.querySelector('input[type="file"]');
      if (input) {
        input.value = '';
      }
      this.image = '';
    },
  },
}))

image хранит выбранный файл как data:image/* — этого достаточно для превью, но для реальной загрузки файл нужно дополнительно отправить на сервер, сам компонент этим не занимается.

Как пользоваться

Набор Куда навесить Что делает
field текстовое поле имени u-prop двусторонне связывает поле с name
picture контейнер превью :style подставляет image фоном, пока он не пуст
initials заглушка внутри превью u-show показывает её, пока файла нет; u-text — первые две буквы name через getInitials(name)
uploader input[type="file"] @change читает выбранный файл в image
remover кнопка «Удалить» u-show появляется, только когда image заполнен; @click передаёт $root и очищает и image, и сам input[type="file"]
