Youla.data: усложняем задачу, упрощаем разметку

Пока состояние компонента — пара плоских свойств, объектный литерал прямо в атрибуте v-data="{...}" — самый короткий путь, как в примерах выше. Но как только в задаче появляется повторяющаяся логика (проверка границ значения, сравнение с текущей активной вкладкой, фильтрация списка) — расписывать её каждый раз внутри выражений в разметке становится многословно и хрупко: одна и та же проверка дублируется в нескольких атрибутах, а любое изменение поведения нужно аккуратно повторить во всех местах.

Youla.data(имя, callback) решает это иначе: даёт компоненту имя, переносит всю логику в обычный JS-объект с методами, а разметка получает только короткие вызовы вроде increment() или isActive('profile'). Такое определение должно быть зарегистрировано раньше, чем Youla.js начнёт разбирать страницу, поэтому вызов оборачивают в событие youla:init, которое библиотека создаёт в самом начале своей работы: 

document.addEventListener('youla:init', () => {
  Youla.data('имя', () => ({
    // свойства и методы компонента
  }));
});

В разметке компонент подключается по имени точно так же, как обычный объект в v-data:

<div v-data="имя">...</div>

Счётчик с ограничениями

Простой count++/count-- из примера выше отлично работает, пока не нужно ограничивать значение диапазоном. Как только появляются нижняя и верхняя границы и шаг изменения, писать проверку прямо в @click для каждой кнопки — а потом ещё раз в :disabled, чтобы кнопка отключалась на границе — становится избыточно. Метод убирает это дублирование: границы и шаг хранятся в данных компонента один раз, а increment()/decrement() сами знают, как их не нарушить. 

document.addEventListener('youla:init', () => {
  Youla.data('counter', () => ({
    min: 0,
    max: 5,
    step: 1,
    value: 0,
    increment() {
      this.value = Math.min(this.value + this.step, this.max);
    },
    decrement() {
      this.value = Math.max(this.value - this.step, this.min);
    },
  }));
});

<div v-data="counter">
  <button type="button" @click="decrement()" :disabled="value <= min">−</button>
  <span v-text="value"></span> / <span v-text="max"></span>
  <button type="button" @click="increment()" :disabled="value >= max">+</button>
</div>
