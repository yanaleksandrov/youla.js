Маска ввода (u-mask)

Директива u-mask ограничивает то, что можно ввести в input, прямо во время набора текста. У неё три режима — они выбираются автоматически по тому, что передано значением атрибута.

Значение Режим
u-mask Пусто/не указано — фильтрует по собственному type поля (tel, number, color, domain).
u-mask="/regexp/" RegExp — вычёркивает из введённого текста всё, что попадает под него.
u-mask="'DD.MM.YYYY'" Строка-паттерн — полноценная маска ввода через библиотеку vanillaTextMask.

u-mask правит только то, что показано в поле — саму разметку value атрибута не трогает. Чтобы сохранить очищенное значение в данные компонента, добавьте к тому же полю u-prop, как в примерах ниже.

Автофильтр по type

Без второго аргумента u-mask смотрит на атрибут type самого поля и вычёркивает символы, которые для этого типа заведомо лишние: пробелы и буквы из телефона, всё кроме цифр и точки из числа, недопустимые символы домена.

Число:
Домен: 
<form u-data>
  <input type="tel" u-mask u-prop="phone">
  <input type="number" u-mask u-prop="amount">
  <input type="domain" u-mask u-prop="domain">
</form>

Свой RegExp

Передайте выражение, возвращающее RegExp — u-mask будет вычёркивать всё, что под него попадает, при каждом нажатии клавиши. Например, промокод только из заглавных латинских букв и цифр: 

<form u-data>
  <input type="text" u-mask="/[^A-Z0-9]/g" u-prop="promo">
  <span u-text="promo"></span>
</form>

Маска по паттерну

Строка целиком — это маска для vanillaTextMask. Она разбирается посимвольно: H/i/D/M — самоограничивающиеся разряды часов, минут, дня и месяца (первая введённая цифра сужает диапазон второй, как в нативных полях даты), Y и 0 — просто цифра, любой другой символ — литерал, который маска подставит сама, а {regexp} — свой класс символов в фигурных скобках, например {[A-Z]} для одной заглавной латинской буквы. Разбирает и применяет маску библиотека vanilla-text-mask — она вшита в сборку Youla.js, подключать отдельно не нужно.

<form u-data>
  <input type="text" u-mask="'+7 (000) 000-00-00'" u-prop="phone">
  <input type="text" u-mask="'DD.MM.YYYY'" u-prop="date">
  <input type="text" u-mask="'HH:ii'" u-prop="time">
  <input type="text" u-mask="'{[A-Z]}{[A-Z]}-0000'" u-prop="serial">
</form>
