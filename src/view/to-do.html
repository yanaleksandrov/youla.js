Список задач

Список To-Do — типовой сценарий для трекера задач. Он переживает перезагрузку страницы: список сохраняется в браузере автоматически. Ниже — весь код, который для этого нужен.

За сохранение списка отвечает модификатор .local в v-data.local="todo": он пишет данные в localStorage при каждом изменении и подставляет их обратно при следующей загрузке страницы.

Сохранённые данные накладываются поверх начальных значений из Youla.data — так новые поля, добавленные в фабрику позже, появятся даже у посетителей со старым localStorage.

Если данные должны быть доступны серверу, замените модификатор на .cookie. Если персистентность не нужна, уберите модификатор — оставьте обычный v-data="todo".

Добавить задачу:

Список задач:

<div v-data.local="todo">
  <p>Добавить задачу:</p>
  <input placeholder="Введите новую задачу..." v-prop="value" v-bind="field" />
  <button type="button" v-bind="adder">Добавить</button>

  <div v-show="tasks.length" hidden>
    <p>Список задач:</p>
    <ul>
      <li v-each="(task, index) in tasks">
        <label>
          <input type="checkbox" v-bind="checkbox"> <span v-bind="status"></span>
        </label>
        <button v-bind="remover">Удалить</button>
      </li>
    </ul>
    <button v-bind="clearer">Очистить всё</button>
  </div>
</div>

document.addEventListener('youla:init', () => {
  Youla.data('todo', () => ({
    value: '',
    tasks: [],
    adder: {
      '@click': "tasks = [...tasks, {title: value, checked: false}]; value = ''",
      ':disabled': '!value.trim()',
    },
    field: {
      '@keydown.enter': "value.trim() && (tasks = [...tasks, {title: value, checked: false}], value = '')",
    },
    checkbox: {
      '@change': 'task.checked = !task.checked',
      ':checked': 'task.checked',
    },
    status: {
      'v-text': 'task.title',
      ':class': "task.checked && 'strike'",
    },
    remover: {
      '@click': 'tasks = tasks.filter((_, i) => i != index)',
    },
    clearer: {
      '@click': 'tasks = []',
    },
  }));
});
