Слайдер диапазона (v-ranger)

Директива v-ranger превращает обычный <input type="range"> в оформленный слайдер: заполненный трек, плавающая подпись значения над ручкой и шкала делений под треком. Если на том же поле стоит атрибут data-points, слайдер автоматически становится диапазонным — появляется вторая ручка, а поле начинает возвращать пару значений. Атрибут data-points задаёт стартовое значение верхней ручки (список через запятую, сегодня используется только первое значение).

min, max, step и стартовое value — обычные HTML-атрибуты поля, как и всегда. Значение директивы — необязательный объект опций, который передаётся напрямую конструктору Ranger.

Опции вкратце

Опция Описание По умолчанию
scaleTicksCount Число делений шкалы под треком; 0 отключает шкалу целиком. 10
scaleMinorTicksCount Промежуточные деления без подписи между каждой парой основных. 0
scaleAnimatedTicksCount Радиус (в делениях) дуги живого CSS-свойства --ranger-scale с каждой стороны от ручки — на нём можно анимировать деления, как полосы графического эквалайзера. 1
labelIsVisible, labelOnDragOnly Показывать ли плавающую подпись значения и показывать ли её только во время перетаскивания. true, false
format Функция (value) => string, которой форматируется значение везде, где оно показывается: в подписи, в делениях шкалы, в aria-valuetext. Может вернуть и HTML-разметку — подпись отрендерит её, а не покажет как экранированный текст. null
values Массив отображаемых значений («S», «M», «L», даты и т.п.) — min/max/step при этом высчитываются автоматически по их числу. null
logScale Отображает значение по экспоненциальной шкале между min и max, хотя перемещение ручки при этом остаётся линейным — для цены товара, где нужна точность и в дешёвом, и в дорогом сегменте одновременно. false
minValue, maxValue Ограничивают выбор поддиапазоном [minValue, maxValue], не трогая нативные min/max — шкала и деления по-прежнему показывают весь диапазон, но ручка останавливается на границах. null, null
snapPoints, snapThreshold Значения, к которым ручка магнитится, оказавшись достаточно близко. [], 0.02
fineStep Шаг для Shift + стрелка — точная подстройка вместо обычного step. по умолчанию step / 10
minGap Минимальное расстояние между ручками в диапазонном режиме. 0
fixedRange В диапазонном режиме фиксирует расстояние между ручками — перетаскивание одной двигает весь диапазон целиком, а не сжимает его. false
marks Точки ({ value }) или зоны ({ from, to }) на треке, независимые от шкалы делений; у любой можно указать свой className. []
fillGradient CSS-фон (например, linear-gradient), которым закрашивается заливка вместо одного сплошного accentColor. null
fromInput, toInput Внешние <input>-элементы, которые держатся синхронными с нижней/единственной и верхней ручками. null
classes Переопределение CSS-классов внутренних элементов слайдера — например, чтобы навесить свой класс на деления шкалы. см. Ranger.DEFAULTS.classes
disabled Блокирует слайдер — стоит продублировать нативным атрибутом disabled на самом поле. false
onStart, onChange, onEnd Коллбэки (value, slider); в диапазонном режиме value — пара [from, to]. null
onFocus, onBlur Коллбэки (value, slider), срабатывающие при получении и потере фокуса ручкой. null

Громкость, яркость и недоступный фильтр

Три базовых состояния: обычный ползунок громкости плеера; компактный ползунок яркости экрана без шкалы и всплывающей подписи (scaleTicksCount: 0, labelIsVisible: false) — для панели быстрых настроек; диапазонный фильтр цены, отключённый через disabled, потому что по текущим условиям поиска нет подходящих товаров. 

<input type="range" min="0" max="100" step="1" value="40"
  v-ranger="{ labelSuffix: '%' }">

<input type="range" min="0" max="10" step="1" value="4"
  v-ranger="{ scaleTicksCount: 0, labelIsVisible: false }">

<input type="range" min="0" max="1000" step="10" value="200" data-points="800" disabled
  v-ranger="{ disabled: true, labelPrefix: '$' }">

Отрицательные и дробные значения: компенсация экспозиции

Произвольный step, отрицательный min, суффикс у меток и делений — как регулятор компенсации экспозиции в камере или фоторедакторе, где нужен шаг в десятые доли ступени в обе стороны от нуля. 

<input type="range" min="-2" max="2" step="0.1" value="-0.3"
  v-ranger="{ scaleTicksCount: 8, scaleTickSuffix: ' EV', labelSuffix: ' EV' }">

Диапазон зарплат, синхронизированный с полями

Два ползунка через data-points задают вилку зарплаты в вакансии, значения дублируются в числовые поля ниже через fromInput/toInput — оба найдены через v-ref и $refs, без единой строчки собственного JS, — а minGap не даёт вилке схлопнуться меньше чем на $1000. 

<div v-data>
  <label>От <input type="number" v-ref="salaryFrom" min="0" max="50000" value="2000"></label>
  <label>До <input type="number" v-ref="salaryTo" min="0" max="50000" value="35000"></label>

  <input
    type="range" min="0" max="50000" step="1" value="2000" data-points="35000"
    v-ranger="{
      fromInput: $refs.salaryFrom,
      toInput: $refs.salaryTo,
      scaleTicksCount: 5,
      minGap: 1000,
      format: value => '$' + value.toLocaleString(),
    }"
  >
</div>

Слипшиеся ползунки и точки привязки: диапазон скидки

Проверка объединения меток при столкновении (ползунки стартуют на расстоянии 4% в диапазоне 0–100%), а snapPoints магнитом притягивает любой из них к стандартным уровням скидки 25%, 50% или 75%, как только он оказывается в пределах snapThreshold от одного из них. 

<input type="range" min="0" max="100" step="1" value="48" data-points="52"
  v-ranger="{ snapPoints: [25, 50, 75], labelSuffix: '%', scaleTickSuffix: '%' }">

Эквалайзер: анимированные деления шкалы

Каждое деление — основное или промежуточное — содержит живое CSS-свойство --ranger-scale (0–1) — дугу с пиком 1 прямо у ручки и плавным (не линейным) спадом к 0 на дальнем краю радиуса, — поэтому анимировать его можно обычным CSS, как подсветку полосы графического эквалайзера; за саму анимацию отвечает готовый модификатор класса ranger-scale-tick--animated из ranger.scss, подключённый здесь через опцию classes. scaleMinorTicksCount добавляет промежуточные деления без подписи между каждой парой основных, а scaleAnimatedTicksCount задаёт радиус этой дуги с каждой стороны от ручки — а диапазонный слайдер ниже подсвечивает деления рядом с любым из двух ползунков независимо, отмечая полосу пропускания фильтра. 

<input
  type="range" min="0" max="100" step="1" value="50"
  v-ranger="{
    scaleTicksCount: 10,
    scaleMinorTicksCount: 9,
    scaleAnimatedTicksCount: 3,
    labelSuffix: '%',
    scaleTickSuffix: '%',
    classes: {
      scaleTick: 'ranger-scale-tick ranger-scale-tick--animated',
      scaleMinorTick: 'ranger-scale-tick ranger-scale-tick--minor ranger-scale-tick--animated',
    },
  }"
>

<input
  type="range" min="0" max="100" step="1" value="20" data-points="80"
  v-ranger="{
    scaleTicksCount: 10,
    scaleMinorTicksCount: 4,
    scaleAnimatedTicksCount: 2,
    labelSuffix: '%',
    scaleTickSuffix: '%',
    classes: {
      scaleTick: 'ranger-scale-tick ranger-scale-tick--animated',
      scaleMinorTick: 'ranger-scale-tick ranger-scale-tick--minor ranger-scale-tick--animated',
    },
  }"
>

Дискретные значения: размер одежды и даты бронирования

values превращает слайдер в выбор индекса по массиву собственных отображаемых значений — min/max/step вычисляются автоматически, как в выборе размера одежды на карточке товара. Массив может содержать что угодно, вплоть до объектов Date: второй слайдер ниже — диапазонный выбор дат для бронирования номера, где сам массив (все дни с 1 по 30 июня 2026) задаёт шкалу целиком, а format отображает значения в читаемом виде. minValue/maxValue при этом ограничивают выбор датами с 5 по 23 июня, когда номер свободен, — шкала по-прежнему показывает весь месяц, но перетащить ручку за эти границы нельзя, она просто останавливается на них. Массив дат и функция форматирования вынесены в Youla.data('bookingDates', ...) — так выражение прямо в v-ranger остаётся коротким. 

<input type="range" value="2" v-ranger="{ values: ['XS', 'S', 'M', 'L', 'XL', 'XXL'] }">

<div v-data="bookingDates">
  <input
    type="range" value="8" data-points="18"
    v-ranger="{ values: dateValues, minValue: 4, maxValue: 22, format: formatBookingDate }"
  >
</div>

Youla.data('bookingDates', () => {
  // 1–30 June 2026 — the array's own bounds are the slider's date limits.
  const dateValues = Array.from({ length: 30 }, (_, i) => {
    const date = new Date(2026, 5, 1);
    date.setDate(date.getDate() + i);
    return date;
  });

  return {
    dateValues,
    // A closure over dateValues, not `this` — Ranger calls format() as its own method, so `this` inside it is the Ranger instance, not this component's data.
    formatBookingDate: (index) => dateValues[Math.round(index)].toLocaleDateString('ru-RU', { day: 'numeric', month: 'short' }),
  };
});

Пользовательское форматирование: тариф облачного хранилища

Функция format(value) полностью заменяет labelPrefix/labelSuffix (и аналогичные параметры для делений шкалы) везде, где отображается значение — здесь она подбирает единицу измерения сама, показывая гигабайты до 1000 и переходя на терабайты после, как в выборе тарифа облачного хранилища. 

<input
  type="range" min="0" max="5000" step="50" value="1250"
  v-ranger="{ scaleTicksCount: 5, format: value => value >= 1000 ? (value / 1000).toFixed(2) + ' ТБ' : value + ' ГБ' }"
>

Логарифмическая шкала: цена товара

logScale оставляет перемещение ручки линейным, но отображает значение по экспоненциальной шкале между min и max — то, что нужно фильтру цены в каталоге, где товары стоят и от 10 центов, и до $10 000: больше точности в частом нижнем сегменте цен, а не только у дорогих редких позиций. Обратите внимание, как значения делений сгущаются слева. Начальный value="10" ниже — это цена в $10, а не позиция ручки: Ranger сам вычисляет нужную позицию при инициализации. Опция format здесь заменяет дефолтную экспоненциальную развёртку своей — она пересчитывает позицию в цену сама, чтобы заодно добавить $ и убрать копейки там, где они уже не важны. 

<input
  type="range" min="0.1" max="10000" step="1" value="10"
  v-ranger="{
    logScale: true,
    scaleTicksCount: 6,
    format: position => {
      const min = 0.1, max = 10000;
      const price = min * Math.pow(max / min, (position - min) / (max - min));
      return price < 10 ? '$' + price.toFixed(2) : '$' + Math.round(price).toLocaleString();
    },
  }"
>

Перетаскивание диапазона: цикл воспроизведения и запись на приём

Схватите саму закрашенную полосу (не ручку) и потяните — оба ползунка двигаются вместе, сохраняя длину, как перемещение окна цикла воспроизведения по треку без изменения его длительности. Работает автоматически на любом диапазонном слайдере, включая первый ниже, где границы цикла по-прежнему можно тянуть и по отдельности, меняя его длину. Второй слайдер — часовой слот записи на приём с fixedRange: за какую бы ручку его ни тянуть, длина не меняется — его можно только передвинуть на другое время. 

<input
  type="range" min="0" max="180" step="1" value="30" data-points="90"
  v-ranger="{ scaleTicksCount: 6, format: seconds => `${Math.floor(seconds / 60)}:${String(Math.round(seconds % 60)).padStart(2, '0')}` }"
>

<input
  type="range" min="480" max="1080" step="15" value="540" data-points="600"
  v-ranger="{ fixedRange: true, scaleTicksCount: 4, format: minutes => `${String(Math.floor(minutes / 60)).padStart(2, '0')}:${String(minutes % 60).padStart(2, '0')}` }"
>

Точный шаг, сброс и метка только при перетаскивании: масштаб

Наведите фокус на ручку: стрелки меняют масштаб на 10% (обычный step), Shift + стрелка — на 1% (fineStep), как точная подстройка зума в графическом редакторе или на карте. Двойной клик по ручке сбрасывает масштаб к 100% — встроенное поведение, без единой строчки своего кода. labelOnDragOnly при этом скрывает всплывающую подпись, пока ручку не начинают двигать — зажмите или перетащите её, чтобы увидеть текущий процент. 

<input
  type="range" min="50" max="200" step="10" value="100"
  v-ranger="{ fineStep: 1, labelOnDragOnly: true, labelSuffix: '%', scaleTickSuffix: '%' }"
>

Градиент заливки: риск портфеля и сложность пароля

fillGradient заменяет один сплошной accent-color CSS-градиентом — здесь зелёный→жёлтый→красный на шкале риска инвестиционного портфеля. В диапазонном режиме градиент растягивается на выбранный поддиапазон, а не на постоянную позицию по всей дорожке. Второй слайдер использует тот же приём для пяти чётких зон — как индикатор сложности пароля (слабый / так себе / хороший / сильный / очень сильный). 

<input
  type="range" min="0" max="100" step="1" value="40"
  v-ranger="{ fillGradient: 'linear-gradient(to right, #22c55e, #eab308, #ef4444)' }"
>

<input
  type="range" min="0" max="100" step="1" value="40"
  v-ranger="{
    fillGradient: 'linear-gradient(to right,
      #00a651 0 calc(20% - 1px), var(--ranger-bg) calc(20% - 1px) 20%,
      #7cb342 20% calc(40% - 1px), var(--ranger-bg) calc(40% - 1px) 40%,
      #fdd835 40% calc(60% - 1px), var(--ranger-bg) calc(60% - 1px) 60%,
      #fb8c00 60% calc(80% - 1px), var(--ranger-bg) calc(80% - 1px) 80%,
      #e53935 80% 100%)',
  }"
>

Метки, зоны и HTML-подпись: недельный бюджет на продукты

marks добавляет фиксированные точки и зоны на дорожку независимо от шкалы делений — здесь отмечены типичный бюджет на продукты (300), рекомендованный (700, выделен своим className) и «комфортная зона» 200–500 через { from, to }. format при этом возвращает HTML — всплывающая подпись рендерит его как разметку, а не показывает как экранированный текст. 

<input
  type="range" min="0" max="1000" step="10" value="450"
  v-ranger="{
    scaleTicksCount: 5,
    marks: [
      { value: 300, label: 'Типично' },
      { value: 700, label: 'Рекомендовано', className: 'ranger-mark--highlight' },
      { from: 200, to: 500, label: 'Комфортная зона' },
    ],
    format: value => '<strong>$' + value.toLocaleString() + '</strong>',
  }"
>

Программное управление: пресеты фильтров

setValue/setRange двигают ручки в обход перетаскивания — через тот же конвейер, что и обычное взаимодействие, как клик по готовому пресету в интерфейсе. update(options) меняет опции уже смонтированного слайдера: «Скрыть фильтры» переключает disabled, «Увеличить лимит» удваивает max у обоих слайдеров ниже и перестраивает их шкалу. Сам экземпляр Ranger директива кладёт на DOM-элемент как el._x_ranger, поэтому до него легко добраться через v-ref и $refs, без отдельной переменной в v-data. 

<div v-data>
  <input type="range" min="0" max="100" step="1" value="50" v-ref="presetVolume" v-ranger="{ labelSuffix: '%' }">
  <input type="range" min="0" max="100" step="1" value="20" data-points="60" v-ref="presetPrice" v-ranger="{ labelPrefix: '$' }">

  <button type="button" @click="$refs.presetVolume._x_ranger.setValue(80)">
    Комфортный уровень
  </button>
  <button type="button" @click="$refs.presetPrice._x_ranger.setRange(30, 70)">
    Средний сегмент
  </button>
  <button
    type="button"
    @click="
      $refs.presetVolume._x_ranger.update({ disabled: !$refs.presetVolume._x_ranger.disabled });
      $refs.presetPrice._x_ranger.update({ disabled: !$refs.presetPrice._x_ranger.disabled })
    "
  >
    Скрыть фильтры
  </button>
  <button
    type="button"
    @click="
      $refs.presetVolume._x_ranger.update({ max: Number($refs.presetVolume._x_ranger.fromSlider.max) * 2 });
      $refs.presetPrice._x_ranger.update({ max: Number($refs.presetPrice._x_ranger.fromSlider.max) * 2 })
    "
  >
    Увеличить лимит
  </button>
</div>

Callback-и и поддержка RTL: громкость в арабском интерфейсе

Потяните или сфокусируйте ручку клавиатурой — каждое событие (onStart, onChange, onEnd, onFocus, onBlur) логируется ниже. Контейнер также имеет dir="rtl" — шкала, заливка, всплывающая подпись и перетаскивание (в т.ч. клик по дорожке и перетаскивание всего диапазона) отражаются автоматически, без какой-либо отдельной настройки, — как регулятор громкости в интерфейсе, локализованном на арабский или иврит. 


    

  

  

    
<div dir="rtl" v-data="{ logText: '' }">
  <input
    type="range" min="0" max="100" step="1" value="50"
    v-ranger="{
      scaleTicksCount: 10,
      labelSuffix: '%',
      onStart: value => logText = 'onStart: ' + value + '\n' + logText,
      onChange: value => logText = 'onChange: ' + value + '\n' + logText,
      onEnd: value => logText = 'onEnd: ' + value + '\n' + logText,
      onFocus: value => logText = 'onFocus: ' + value + '\n' + logText,
      onBlur: value => logText = 'onBlur: ' + value + '\n' + logText,
    }"
  >
  <pre v-text="logText"></pre>
</div>
