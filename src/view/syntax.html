Полный синтаксис

Эта страница — краткая сводка всего синтаксиса Youla.js в одном месте: типы атрибутов, директивы и их модификаторы, специальные переменные в выражениях. За подробностями и живыми примерами каждой директивы переходите по ссылке в соответствующей таблице.

Типы атрибутов

Синтаксис Назначение Пример
v-data Отмечает элемент как корень компонента и задаёт его реактивные данные <div v-data="{ count: 0 }">
v-* Директива — привязывает поведение или содержимое элемента к данным <div v-show="open">
:атрибут Динамическая привязка значения обычного HTML-атрибута к данным <img :src="url">
@событие Слушатель события браузера, с поддержкой модификаторов <button @click="open = true">
v-ref Именует элемент для доступа через $refs внутри выражений <video v-ref="player">

Директивы

Директива Модификаторы Описание
v-data .local, .cookie Определяет компонент и его начальные данные
v-text — Текстовое содержимое элемента, HTML-теги экранируются
v-html — HTML-содержимое элемента без экранирования (только для доверенного контента)
v-show .lazy Переключает видимость элемента через display, не удаляя его из DOM
v-each .lazy Клонирует элемент-шаблон для каждого элемента массива, объекта или диапазона чисел
v-prop .number, .trim, .lazy, .local, .cookie Двусторонняя привязка значения поля формы (input, select, textarea) к данным
v-bind — Задаёт директивы, события и атрибуты элемента одним JS-объектом вместо перечисления в разметке

Синтаксис v-each

item in items                  — перебор массива
(item, index) in items         — перебор массива с доступом к индексу
(item, key) in object          — перебор пар "ключ: значение" объекта
item in 5                      — диапазон чисел (здесь: от 1 до 5)
item in items join ', '        — со вставкой текстового разделителя между элементами

Подробности и живые примеры — на странице v-each.

Модификаторы событий

Модификатор Описание
.preventВызывает event.preventDefault()
.stopВызывает event.stopPropagation()
.outsideСрабатывает при клике за пределами элемента
.windowСлушает событие на window вместо самого элемента
.documentСлушает событие на document вместо самого элемента
.passiveРегистрирует слушатель с { passive: true }
.captureРегистрирует слушатель с { capture: true }
.onceОбработчик срабатывает только один раз
.delay.250msОткладывает вызов обработчика на указанное время

Помимо стандартных событий браузера поддерживаются два особых: @load — срабатывает сразу при инициализации элемента, и @intersect — когда элемент появляется в области видимости. Подробности — на странице События.

Специальные переменные в выражениях

Переменная Доступна в Значение
$el обработчиках событий, v-prop DOM-элемент, на котором объявлено выражение
$event обработчиках событий объект события браузера
$refs обработчиках событий доступ к элементам, помеченным атрибутом v-ref
$root обработчиках событий корневой элемент компонента (тот, на котором объявлен v-data)
$имяМетода любых выражениях метод, зарегистрированный через Youla.method()

Выражения

В значение любой директивы или события можно передать произвольное JavaScript-выражение: сравнения (count > 0), тернарные операторы, шаблонные строки, вызовы методов, доступ к вложенным свойствам через точечную нотацию (user.profile.name) — всё, что вычисляется в одну строку.

<%= _.template(require('./parts/footer.html').default)(data) %>
