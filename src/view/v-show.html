v-show

Директива v-show управляет видимостью элемента через свойство display. Элемент остаётся в DOM всегда — переключается только его отображение.

Это делает переключение мгновенным: элемент не нужно создавать заново и повторно инициализировать, как это было бы при добавлении и удалении из DOM. 

<div v-data="{ open: false }">
  <button @click="open = ! open">Переключить</button>

  <div v-show="open">
    Контент...
  </div>
</div>

Нажатие на кнопку «Переключить» меняет значение open, а v-show показывает или скрывает блок вслед за ним.

Любое выражение вместо простого флага

В v-show можно передать любое выражение, а не только имя булевой переменной — оно будет вычислено и приведено к true/false при каждом обновлении данных. 

<div v-data="{ cart: ['Book', 'Pen'] }">
  <button @click="cart = [...cart, 'Book']">Добавить в корзину</button>
  <button @click="cart = []">Очистить корзину</button>

  <p v-show="cart.length > 0">Товаров в корзине: <strong v-text="cart.length"></strong></p>
  <p v-show="cart.length === 0">Корзина пуста</p>
</div>

Переключение вкладок

Одна переменная может управлять сразу несколькими блоками v-show, что удобно для реализации вкладок, аккордеонов и похожих интерфейсов. 

<div v-data="{ tab: 'profile' }">
  <button @click="tab = 'profile'">Профиль</button>
  <button @click="tab = 'settings'">Настройки</button>

  <div v-show="tab === 'profile'">Здесь данные профиля.</div>
  <div v-show="tab === 'settings'">Здесь настройки аккаунта.</div>
</div>

Совместимость с flex, grid и другими значениями display

При первом обращении к элементу v-show запоминает его исходное инлайн-значение display (или пустую строку, если оно не задано).

При показе директива восстанавливает именно это значение, а не принудительно проставляет display: block. Поэтому flex, grid, inline-flex и другие значения работают без лишнего CSS и !important. 

<div v-data="{ open: true }">
  <button @click="open = ! open">Переключить</button>

  <div v-show="open" style="display: flex; gap: 8px;">
    <span>Элемент 1</span>
    <span>Элемент 2</span>
  </div>
</div>
Элемент 1 Элемент 2

Если элемент изначально скрыт (v-show="false" при загрузке), браузер может показать его на долю секунды раньше, чем Youla.js завершит инициализацию — этот эффект называют «мерцанием страницы».

Чтобы избежать мерцания, добавьте элементу атрибут hidden и следующее CSS-правило: 

[hidden] { display: none !important; }

Дальше атрибут поддерживается директивой автоматически: как только элемент нужно показать, v-show сам снимает hidden, а не только меняет инлайн-display.

Если v-show нужно переключать вместе с другими директивами и событиями как единый набор, посмотрите v-bind.
