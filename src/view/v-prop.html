u-prop

Директива u-prop связывает поле формы — input, select или textarea — с данными компонента u-data одним атрибутом, без ручного объявления значения и обработчика ввода.

Меньше кода. Без u-prop значение пришлось бы объявлять дважды — атрибутом value/checked в разметке и отдельным ключом в объекте u-data, вручную синхронизируя оба места.

А затем вручную вешать @input/@change, который читает $el.value (или $el.checked, выбранные <option> — по-своему для каждого типа поля) и пишет это в данные. Сравните два одинаковых по смыслу подхода: 

<form u-data>
  <input type="text" value="Hello" u-prop="test">
  <span u-text="test"></span>
</form>
 
<form u-data="{test: 'Hello'}">
  <input type="text" value="Hello" @keydown.delay.1ms="test = $el.value">
  <span u-text="test"></span>
</form>

В первом случае, с u-prop, не требуется ни отдельного объявления значения в u-data, ни обработчика события ввода — всё это делает один атрибут на поле формы.

Мерцание при загрузке. u-prop считывает значение поля прямо из уже отрисованной разметки при инициализации компонента — до того, как данные становятся реактивными.

Поэтому состояние в u-data сразу совпадает с тем, что видно на экране. При ручном подходе значение и атрибут value объявлены отдельно: стоит им разойтись — и зависящая от них разметка на первом кадре покажет неверное значение.

Разные типы полей. Чекбоксы, радиокнопки и select по-разному хранят своё значение в DOM. u-prop сам определяет тип поля и обрабатывает его — писать отдельную логику синхронизации для каждого вида не нужно.

Модификаторы .number и .trim берут на себя приведение типов и очистку пробелов, а .local/.cookie — сохранение значения поля между перезагрузками страницы браузера.

<form u-data>
  <input u-prop="message" type="text">
  <span u-text="message"></span>
</form>

Модификаторы

.number

По умолчанию u-prop хранит значение поля как строку. Добавьте модификатор .number, чтобы Youla.js автоматически приводила его к числовому типу данных.

Значение: , тип: 
<form u-data>
  <input type="text" value="10" u-prop.number="age">
  <div>Значение: <span u-text="age"></span>, тип: <span u-text="typeof age"></span></div>
</form>

.trim

Убирает пробелы в начале и конце введённого значения — полезно для полей вроде email или логина, где лишние пробелы мешают. В примере ниже пробел обрезается при каждом нажатии клавиши. 

<form u-data>
  <input type="text" u-prop.trim="name">
  <div u-text="name"></div>
</form>

Если пробелы нужно убирать только после завершения ввода, а не при каждом нажатии клавиши, добавьте к u-prop.trim ещё и модификатор .lazy для этого поля. 

<form u-data>
  <input type="text" u-prop.lazy.trim="name">
  <div u-text="name"></div>
</form>

.local и .cookie

Сохраняют значение поля в localStorage или куках и восстанавливают его при следующей загрузке страницы — удобно для пользовательских настроек, например темы оформления.

Чем local storage и куки отличаются по объёму и назначению и как выбрать между ними — читайте на странице u-data, в разделе про модификаторы .local и .cookie.

Сохранение в local storage

Сохранение в куках
<form u-data>
  <div>Сохранение в local storage</div>
  <input type="text" u-prop.local="firstName">
  <div u-text="firstName"></div>
  <br>
  <div>Сохранение в куках</div>
  <input type="text" u-prop.cookie="lastName">
  <div u-text="lastName"></div>
</form>
