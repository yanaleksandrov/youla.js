v-each

Директива v-each создаёт элемент разметки для каждого значения массива, объекта или диапазона чисел. Она клонирует DOM-узел, на котором объявлена, поэтому список всегда отражает актуальное состояние данных.

Пример ниже показывает список цветов на основе массива — каждый элемент li создаётся автоматически, по одному на каждый цвет из исходного массива данных. 

<div v-data="{ colors: ['Red', 'Orange', 'Yellow'] }">
  <ul>
    <li v-each="color in colors" v-text="color"></li>
  </ul>
</div>

Важное правило: атрибут v-each ставится на тот элемент, который нужно повторить — а не на его родителя или потомка, иначе клонируется не то, что вы ожидаете.

Сам элемент-шаблон остаётся в разметке как образец для клонирования, поэтому его стоит скрыть css-правилом display: none для селектора [v-each] на странице.

Вы также можете передавать объекты и разбирать их следующим синтаксисом, получая одновременно ключ и значение каждого свойства прямо внутри шаблона списка. 

  <ul v-data="{ cars: { make: 'Jeep', model: 'Grand Cherokee', color: 'Black' } }">
    <li v-each="(car, key) in cars">
      <span v-text="key"></span>: <span v-text="car"></span>
    </li>
  </ul>

Массив объектов

Самый частый случай на практике — перебор массива объектов. Поля текущего элемента доступны в шаблоне через точечную нотацию, без дополнительной настройки. 

<ul v-data="{
  users: [
    { name: 'Ian', role: 'Admin' },
    { name: 'Olga', role: 'Editor' },
    { name: 'Denis', role: 'Viewer' },
  ]
}">
  <li v-each="user in users">
    <strong v-text="user.name"></strong> — <span v-text="user.role"></span>
  </li>
</ul>
  • —

А также создавать вложенные циклы с неограниченной глубиной — например, категории товаров, где у каждой категории свой список товаров и их характеристик. 

<div v-data="{
  categories: [
    {
      name: 'Category 1',
      products: [
        { name: 'Product 1' },
        { name: 'Product 2' },
      ]
    },
    {
      name: 'Category 2',
      products: [
        { name: 'Product 3', attributes: ['10x50mm', 'Yellow'] },
        { name: 'Product 4', attributes: ['30x40mm', 'White'] },
        { name: 'Product 5', attributes: ['20x20mm', 'Black'] },
      ]
    }
  ]
}">
  <div v-each="(category, index) in categories">
    <h3 v-text="category.name"></h3>
    <ul>
      <li v-each="product in category.products">
        <strong v-text="product.name"></strong>
        Attributes:
        <em v-each="attribute in product.attributes join ', '" v-text="attribute"></em>
      </li>
    </ul>
  </div>
</div>

Независимость списков друг от друга

Каждый элемент с v-data — самостоятельный компонент со своими данными, поэтому на странице можно свободно размещать сколько угодно независимых v-each, в том числе вложенных.

Переменные цикла одного компонента не видны другому, так что в соседних списках можно спокойно использовать одинаковые имена, например item, без конфликтов. 

<ul v-data="{ fruits: ['Apple', 'Banana'] }">
  <li v-each="item in fruits" v-text="item"></li>
</ul>

<ul v-data="{ tools: ['Hammer', 'Wrench'] }">
  <li v-each="item in tools" v-text="item"></li>
</ul>

Добавление разделителя

Ключевое слово join вставляет текстовый разделитель между элементами — например, запятую или пробел — без ручной проверки, последний ли это элемент списка. 

<p v-data="{ attributes: ['White', '20x30mm', 'Google LLC'] }">
  Характеристики: <i v-each="attribute in attributes join ', '" v-text="attribute"></i>
</p>

Доступ к индексам

Чтобы получить индекс текущего элемента в цикле, используйте синтаксис (item, index) in items — индекс становится доступен в шаблоне наравне с самим значением. 

<ul v-data="{ names: ['Ivan', 'Yulia', 'Evgeny'] }">
  <li v-each="(name, index) in names">
    <span v-text="`${++index}: ${name}`"></span>
  </li>
</ul>

Динамическое обновление списка

Список реактивен: как только массив получает новое значение, v-each автоматически перерисовывает разметку, без ручного вызова каких-либо методов обновления.

Важно: обновляйте список присваиванием нового значения — через spread-синтаксис или .slice() — а не мутирующими методами вроде .push(). Система реактивности отслеживает именно присваивание. 

<div v-data="{ fruits: ['Apple', 'Banana'] }">
  <button type="button" @click="fruits = [...fruits, 'Cherry']">Добавить</button>
  <button type="button" @click="fruits = fruits.slice(0, -1)">Удалить последний</button>
  <ul>
    <li v-each="fruit in fruits" v-text="fruit"></li>
  </ul>
</div>

Итерация по диапазону

Чтобы просто повторить блок N раз, не создавая массив, укажите целое число вместо свойства данных — удобно для рейтингов, шагов мастера и похожих счётчиков. 

<div v-data>
  Рейтинг:
  <span v-each="i in 5">⭐</span>
</div>
Рейтинг: ⭐

Обратите внимание, что в таком случае значения i начинаются с единицы, а не с нуля, в отличие от привычных нулевых индексов обычного массива в JavaScript.

Модификаторы

.lazy

Пропускает рендер списка при инициализации компонента и включается только при изменении привязанных данных. Это устраняет мерцание (flickering) страницы и помогает SEO.

Как это работает

Первичный рендеринг делает сервер: браузер сразу показывает готовый контент, не дожидаясь загрузки и выполнения JavaScript-кода библиотеки на клиенте.

После загрузки JS происходит гидратация — Youla.js «привязывает» данные к уже готовому HTML, включая интерактивность и последующие реактивные обновления. 

<div v-data="{devices: []}">
  <button type="button" @click="devices = ['Headphones', 'VR Glasses']">Обновить список</button>
  <ul>
    <li v-each.lazy="device in devices" v-text="device"></li>
    <li>Phones</li>
    <li>Laptops</li>
  </ul>
</div>
