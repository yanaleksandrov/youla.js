Атрибуты

Youla.js предоставляет простой способ динамически управлять атрибутами HTML-элементов на основе текущего состояния данных. Синтаксис реализуется через добавление двоеточия перед названием атрибута — значением может быть любое выражение, которое пересчитывается заново при каждом изменении связанных данных. 

<tag :атрибут="выражение"></tag>

Вот простой пример реализации смены цвета кнопки: 

<div class="demo" v-data="{isRed: false}">
  <button @click="isRed = !isRed" :style="isRed && {color: 'red'}">Toggle Color</button>
</div>

Синтаксис : может применяться ко всем стандартным HTML-атрибутам, включая текстовые (href, src, title, placeholder), булевые (disabled, checked, readonly, required), объектные (class, style) и пользовательские (data-*, aria-*).

Булевые атрибуты

Атрибуты disabled, readonly, required, checked, autofocus, autoplay и hidden устроены по-особому: Youla.js добавляет их, только если выражение истинно, и полностью удаляет, если ложно — а не выставляет строку "true"/"false", которую браузер воспринял бы как атрибут, включённый в любом случае. 

<div v-data>
  <label>
    <input type="checkbox" v-prop="agree"> Я согласен с условиями
  </label>
  <button :disabled="!agree" disabled>Продолжить</button>
</div>

Классы (:class)

Значением :class может быть строка, массив классов или объект, где ключ — имя класса, а значение — выражение, включающее или выключающее его. Объектная форма особенно удобна для переключения активного пункта меню или вкладки. 

<ul v-data="{ tab: 'profile' }">
  <li :class="{ active: tab === 'profile' }" @click="tab = 'profile'">Профиль</li>
  <li :class="{ active: tab === 'settings' }" @click="tab = 'settings'">Настройки</li>
</ul>

Массив и строка работают так же, как обычная конкатенация классов:

<div v-data="{ size: 'card--small' }">
  <div :class="['card', size]" v-text="'Массив'"></div>
  <div :class="'card ' + size" v-text="'Строка'"></div>
</div>

Стили (:style)

Помимо строки (см. первый пример на этой странице), :style принимает объект. Ключи в camelCase автоматически превращаются в kebab-case, а CSS-переменные (начинающиеся с --) передаются как есть. 

<div v-data="{ size: 24, color: '#0e7a6b' }">
  <button @click="size += 4">Увеличить</button>
  <p :style="{ fontSize: `${size}px`, '--accent': color, color: 'var(--accent)' }">
    Пример текста
  </p>
</div>

Произвольные и data-/aria-атрибуты

Любой нестандартный атрибут, включая data-* и aria-*, привязывается точно так же. Это удобно для передачи состояния сторонним скриптам или для доступности. 

<div v-data="{ open: false }">
  <button @click="open = !open" :aria-expanded="open" :data-state="open ? 'expanded' : 'collapsed'">
    Подробнее
  </button>
</div>

Несколько атрибутов на одном элементе

Директив :атрибут на одном элементе может быть сколько угодно — например, кнопка сохранения, которая одновременно блокируется, меняет класс и подсказку в зависимости от состояния формы. 

<div v-data="{ saving: false }">
  <button
    @click="saving = true"
    :disabled="saving"
    :class="{ 'is-loading': saving }"
    :title="saving ? 'Идёт сохранение…' : 'Сохранить изменения'"
    v-text="saving ? 'Сохранение…' : 'Сохранить'"
  >Сохранить</button>
</div>

Внутри v-each

Привязка атрибутов работает и на элементах, созданных директивой v-each, обращаясь к текущему элементу итерации — например, чтобы раскрасить бейджи приоритета задач. 

<ul v-data="{
  tasks: [
    { title: 'Написать отчёт', priority: 'high' },
    { title: 'Проверить почту', priority: 'low' },
    { title: 'Согласовать бюджет', priority: 'medium' },
  ]
}">
  <li v-each="task in tasks">
    <span :style="{
      color: task.priority === 'high' ? 'crimson' : (task.priority === 'medium' ? 'darkorange' : 'seagreen')
    }" v-text="task.priority"></span>
    <span v-text="task.title"></span>
  </li>
</ul>

Когда на одном элементе накапливается сразу несколько таких атрибутов вместе с директивами и событиями, удобнее вынести их в один переиспользуемый набор через v-bind, вместо того чтобы перечислять их в разметке по отдельности.
