Список задач

Практический пример, который показывает, как несколько директив Youla.js работают вместе в одном небольшом компоненте: v-prop связывает поле ввода с данными, v-each строит список задач, v-show прячет список и кнопку очистки, пока задач нет, а :class и v-text отображают состояние каждой задачи. Каждый элемент разметки — кнопка добавления, чекбокс, подпись задачи, кнопка удаления и кнопка очистки — получает свой набор атрибутов и событий через v-bind, поэтому в разметке не осталось ни одной инлайновой директивы или обработчика: только имя набора. 

document.addEventListener('youla:init', () => {
  Youla.data('todo', () => ({
    value: '',
    tasks: [],
    adder: {
      '@click': "tasks = [...tasks, {title: value, checked: false}]; value = ''",
      ':disabled': '!value.trim()',
    },
    checkbox: {
      '@change': 'task.checked = !task.checked',
      ':checked': 'task.checked',
    },
    status: {
      'v-text': 'task.title',
      ':class': "task.checked && 'strike'",
    },
    remover: {
      '@click': 'tasks = tasks.filter((_, i) => i != index)',
    },
    clearer: {
      '@click': 'tasks = []',
    },
  }));
});

<div v-data="todo">
  <p>Добавить задачу:</p>
  <input placeholder="Введите новую задачу..." v-prop="value" />
  <button type="button" v-bind="adder">Добавить</button>

  <div v-show="tasks.length" hidden>
    <p>Список задач:</p>
    <ul>
      <li v-each="(task, index) in tasks">
        <label>
          <input type="checkbox" v-bind="checkbox"> <span v-bind="status"></span>
        </label>
        <button v-bind="remover">Удалить</button>
      </li>
    </ul>
    <button v-bind="clearer">Очистить всё</button>
  </div>
</div>

checkbox, status и remover — свойства со строками-выражениями, определённые на верхнем уровне компонента, но используются они на элементах внутри v-each и там же получают доступ к переменным цикла task и index — так же, как строки внутри v-bind получают их на странице v-bind. У remover всего один ключ, но он всё равно вынесен в набор — ради единообразия: в разметке компонента не осталось ни одного элемента с обработчиком или директивой, написанными напрямую.
