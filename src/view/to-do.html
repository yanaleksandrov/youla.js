Список задач

Практический пример, который показывает, как несколько директив Youla.js работают вместе в одном небольшом компоненте: v-prop связывает поле ввода с данными, v-each строит список задач, v-show прячет список и кнопку очистки, пока задач нет, а :class и v-text отображают состояние каждой задачи. 

<div class="demo" v-data="{tasks: []}">
  <div>Добавить задачу:</div>
  <input placeholder="Введите новую задачу..." v-prop="value" />
  <button type="button" @click="tasks = [...tasks, {title: value, checked: false}]; value = ''" :disabled="!value.trim()">Добавить</button>
  <br>

  <div v-show="tasks.length" hidden>
    <p>Список задач:</p>
    <ul>
      <li v-each="(task, index) in tasks">
        <label>
          <input type="checkbox" @change="task.checked = !task.checked" :checked="task.checked">
          <span v-text="task.title" :class="task.checked && 'strike'"></span>
        </label>
        <button @click="tasks = tasks.filter((_, i) => i != index)">Удалить</button>
      </li>
    </ul>
    <button v-show="tasks.length" @click="tasks = []" hidden>Очистить всё</button>
  </div>
</div>
