Youla.js строится вокруг одной идеи: HTML на странице должен быть готов ещё до того, как загрузится JavaScript. За данные и разметку отвечает сервер, а библиотека — только за интерактивность поверх неё. Это не ещё один способ отрисовать интерфейс на клиенте, а инструмент гидратации: Youla.js читает уже готовую разметку и оживляет её директивами, ничего не перерисовывая заново.

Поэтому основная задача разработчика — правильно получить и вывести данные на сервере. Youla.js включается уже после — без мерцания страницы и без проблем с индексацией контента.

Основная философия

Страница остаётся читаемой и рабочей, даже если JavaScript не загрузился или отключён — ссылки и формы работают как обычный HTML, а не как пустой контейнер в ожидании скрипта.

Поисковые роботы и парсеры соцсетей видят готовый контент сразу, а не пустой <div>, который нужно дождаться и выполнить, чтобы получить текст страницы.

Модификатор .lazy у v-each и v-prop, а также автоматическая синхронизация атрибута hidden у v-show — прямые следствия этого подхода: они помогают сохранить то, что уже видно пользователю при первой загрузке страницы.

Youla.js не трогает то, что сервер уже отрисовал верно — в некоторых подходах контент при инициализации переотрисовывается или временно заменяется, до готовности скрипта.

Библиотеке не нужен виртуальный DOM и сравнение деревьев — она читает конкретный элемент и директиву на нём, поэтому клиентский код маленький и работает с любым бэкендом.

Установка

Youla.js пока не публикуется как npm-пакет — библиотеку нужно собрать из исходников репозитория самостоятельно. Процесс простой и обычно занимает не больше пары минут, даже при первом знакомстве с проектом.

Клонируйте репозиторий

git clone https://github.com/yanaleksandrov/Youla.js.git
cd Youla.js

Установите зависимости и соберите проект

npm install
npm run build

После сборки в папке dist появятся два файла: youla.js для разработки с читаемым кодом и минифицированный youla.min.js, который стоит подключать в готовом проекте.

Подключите библиотеку на странице

<script src="dist/youla.min.js"></script>

Youla.js сама находит на странице все элементы с атрибутом v-data и инициализирует их при загрузке — вызывать что-либо вручную или настраивать точку входа не требуется.

Общая рекомендация

Держите JavaScript отдельно от разметки. Простое состояние удобно описывать прямо в v-data="{ ... }". Но как только логики становится больше, выносите её в отдельный JS-файл, а не разрастайте атрибут.

Youla.data(имя, callback) регистрирует именованный компонент со своими данными и методами — в разметке остаётся только короткая ссылка на имя, а не весь объект целиком.

Youla.method() делает то же самое для переиспользуемых функций: результат доступен как $имяМетода в любом выражении, без копирования одной логики по всей разметке.
