Копирование в буфер обмена

Кнопка «Скопировать» берёт текст поля через $refs, копирует его в буфер обмена и на полторы секунды показывает подпись «Скопировано!».

У кнопки два динамических атрибута — клик и подпись, — поэтому они собраны в один набор action и подключены через v-bind="action" вместо двух отдельных атрибутов. 

document.addEventListener('youla:init', () => {
  Youla.data('clipboard', () => ({
    copied: false,
    copy(text) {
      navigator.clipboard.writeText(text).then(() => {
        this.copied = true;

        setTimeout(() => this.copied = false, 1500);
      });
    },
    action: {
      '@click': 'copy($refs.snippet.value)',
      'v-text': "copied ? 'Скопировано!' : 'Скопировать'",
    },
  }));
});

<div v-data="clipboard">
  <input v-ref="snippet" value="npm install youla.js" readonly>
  <button type="button" v-bind="action"></button>
</div>

$refs доступен только в выражениях разметки, поэтому action оформлен строками, а не методами: строка '@click' вычисляется так же, как если бы была написана прямо в атрибуте, и видит $refs.

Метод получил бы только this с данными компонента — без $refs, $el и $event. Подробнее об этом различии — на странице v-bind.

navigator.clipboard работает только в защищённом контексте — на localhost и по HTTPS. Если открыть страницу по обычному HTTP, браузер молча откажет в разрешении, и copied просто не переключится.
