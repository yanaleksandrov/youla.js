Загрузчик аватарки

Форме профиля обычно нужен загрузчик фото: показать превью сразу после выбора файла, до отправки на сервер, и чем-то заменить пустое место, пока файл не выбран — обычно инициалами пользователя. 

Youla.data('avatar', () => ({
  name: '',
  image: '',
  field: {
    'v-prop': 'name',
  },
  picture: {
    ':title': 'name',
    ':style': "image && `background-image:url(${image})`",
  },
  initials: {
    'v-show': '!image',
    'v-text': `name && getInitials(name)`,
  },
  uploader: {
    '@change': 'add($event)',
  },
  remover: {
    '@click': 'remove($root)',
    'v-show': 'image',
  },
  add(event, callback) {
    let file = event.target.files[0];
    if (file) {
      let reader = new FileReader();
      reader.onload = e => this.image = e.target.result;
      reader.readAsDataURL(file);
    }

    callback?.();
  },
  remove(root) {
    let input = root.querySelector('input[type="file"]');
    if (input) {
      input.value = '';
    }
    this.image = '';
  },
  getInitials(string, letters = 2) {
    return string.split(' ', letters).map(word => word.charAt(0)).join('').toUpperCase();
  },
}))

<div class="demo example-avatar" v-data="avatar">
  <div class="avatar-circle" v-bind="picture">
    <span v-bind="initials" hidden></span>
  </div>

  <input type="text" placeholder="Введите имя" v-bind="field">

  <input type="file" accept="image/*" v-bind="uploader">

  <button type="button" v-bind="remover" hidden>Удалить</button>
</div>

image хранит выбранный файл как data:-URL — этого достаточно для превью, но для реальной загрузки файл нужно дополнительно отправить на сервер, сам компонент этим не занимается.

Как пользоваться

Набор Куда навесить Что делает
field текстовое поле имени v-prop двусторонне связывает поле с name
picture контейнер превью :style подставляет image фоном, пока он не пуст
initials заглушка внутри превью v-show показывает её, пока файла нет; v-text — первые две буквы name через getInitials(name)
uploader input[type="file"] @change читает выбранный файл в image
remover кнопка «Удалить» v-show появляется, только когда image заполнен; @click передаёт $root и очищает и image, и сам input[type="file"]
