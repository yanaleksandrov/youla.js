Filler (v-filler)

Директива v-filler превращает обычный <input type="text"> в поле выбора цвета в духе Figma: квадратный образец цвета, поле HEX-значения и поле прозрачности (0-100%) — перетащить подпись «%» можно прямо мышью, влево-вправо. В поле HEX можно вставить или ввести цвет сразу вместе с прозрачностью — восьмизначный HEX (#RRGGBBAA) или строку вида rgba(...) — оба значения применятся одним действием.

Клик по HEX-полю открывает выпадающий список с ручным вводом и палитрой (список «цвет + название»), плюс свой набор цветов. Клик по образцу открывает полноценный диалог с кнопками «Заливка»/«Изображение»/«Видео»: «Заливка» — это HSV + прозрачность с кнопкой копирования значения в буфер обмена, «Изображение» и «Видео» — поле загрузки файла с одинаковым набором настроек (object-fit, поворот, коррекция). Значение директивы — необязательный объект опций, который передаётся напрямую конструктору Filler. Само поле всегда показывает цвет в HEX, независимо от формата, выбранного в диалоге (HEX / RGB / HSL). И выпадающий список, и диалог никогда не бывают уже самого поля — по ширине они всегда подстраиваются под него. Появляются они справа или слева от поля; только если места не хватает ни с одной стороны — снизу или сверху, со своей прокруткой, если и там места мало.

Опции вкратце

Опция Описание По умолчанию
alpha Стартовая прозрачность (0-100); если не задана, читается из data-alpha поля, иначе — 100. null
format Формат полей и кнопки копирования внутри диалога — 'hex', 'rgb' или 'hsl'. Само поле рядом с образцом цвета всегда остаётся HEX. 'hex'
palette Массив { name, hex } для списка «Библиотека» в выпадающем меню — сортируется по name при отрисовке, каждая строка показывает цвет и название вместе. встроенный набор именованных цветов
sources Какие кнопки типа заливки показывать над образцом цвета — любой набор из 'solid', 'image', 'video'. Если оставить только один тип, кнопки скрываются, а диалог сразу открывается на этом типе. ['solid', 'image', 'video']
customPaletteKey Ключ localStorage, под которым хранится свой набор цветов пользователя; null отключает сохранение между визитами. 'youla-filler-palette'
suffixText Текст после значения прозрачности; перетаскивание этой подписи мышью меняет значение. '%'
disabled Блокирует поле целиком — открытие диалога/списка, ввод и перетаскивание. false
onChange Функция (hex, alpha) => void, вызывается при любом изменении цвета или прозрачности. null
classes Переопределение CSS-классов внутренних элементов пикера. см. Filler.DEFAULTS.classes

Изоляция стилей выпадающего списка и диалога

Само поле (образец, HEX, «%») — обычная разметка страницы. Выпадающий список и диалог рендерятся внутри отдельного shadow root: стили страницы туда не проникают, а стили этих панелей не просачиваются наружу. Опция classes по-прежнему задаёт названия классов внутри панели, но переопределить их стили снаружи обычным селектором нельзя — вместо этого у каждого элемента панели есть атрибут part, повторяющий его класс, и достучаться до него можно через ::part(): 

<style>
  /* сработает для любого v-filler на странице, у которого открыт диалог */
  div::part(filler-dialog) { border-radius: 12px; }
  div::part(filler-dialog-area) { height: 200px; }
</style>

Базовое использование

Начальный цвет и прозрачность читаются из value и data-alpha.

<input type="text" value="#FF6F59" data-alpha="80" v-filler>

Пипетка с экрана

Взять цвет прямо с экрана можно двумя способами: зажать Alt и кликнуть по образцу цвета, либо открыть диалог и нажать на иконку пипетки рядом с кнопкой копирования. Выбранный цвет применяется так же, как клик по цвету из палитры, — совпадает он с сохранённым цветом или нет, для результата не важно.

Про EyeDropper

Пипетка работает через браузерный API EyeDropper, который пока поддерживают только Chromium-браузеры (Chrome, Edge). Там, где он не поддерживается, кнопка в диалоге не отображается, а клик с Alt по образцу просто открывает диалог как обычно.

Реакция на изменения

onChange получает актуальные HEX и прозрачность при любой правке — вводе HEX, перетаскивании ползунков диалога или значения «%». Кнопка «⧉» в диалоге копирует текущий цвет строкой в том формате, что выбран на вкладках (HEX/RGB/HSL), с учётом прозрачности.

Текущее значение: 

<input
  type="text"
  value="#2196F3"
  v-filler="{ onChange: (hex, alpha) => result = `${hex}, ${alpha}%` }"
>
<p>Текущее значение: <code v-text="result"></code></p>

Свой формат и своя палитра

Диалог можно открыть сразу в формате rgb, а список библиотеки — сузить до нужных брендовых цветов. 

<input
  type="text"
  value="#8F00FF"
  v-filler="{
    format: 'rgb',
    palette: [
      { name: 'Brand Purple', hex: '#8F00FF' },
      { name: 'Brand Teal', hex: '#0E7A6B' },
      { name: 'Brand Amber', hex: '#A85417' },
    ],
  }"
>

Заливка изображением и видео

Кнопки «Заливка», «Изображение» и «Видео» над образцом цвета переключают тип заливки, а не просто вкладку диалога: пока активна «Изображение» или «Видео», образец показывает живую миниатюру файла (с учётом поворота и прозрачности — видео при этом проигрывается прямо в образце, без звука и по кругу), а само поле вместо HEX показывает текст «Изображение»/«Видео» и становится нередактируемым. Подписи берутся из labels.imageSource, labels.videoSource и labels.solidSource.

Файл можно перетащить или вставить (Ctrl+V) прямо на образец цвета — заливка сразу переключится на «Изображение» или «Видео» (в зависимости от типа файла) и подставит его, без дополнительных кликов. В самой панели: селект object-fit, кнопка поворота на 90°, клик по уже загруженному файлу открывает выбор заново (чтобы заменить), крестик в углу — убирает файл. Дальше «Изображение» и «Видео» расходятся — у каждого свой набор настроек под превью.

Коррекция изображения

У «Изображения» — по одному ползунку на каждую функцию CSS filter; диапазон каждого ограничен тем, что допускает сама функция:

Функция Диапазон Нейтральное значение
brightness, contrast, saturate 0-200% 100%
grayscale, sepia, invert 0-100% 0%
blur 0-20px 0px
hue-rotate -180…180° 0°

Подписи ползунков берутся из labels.filters (по одному ключу на каждый фильтр).

Настройки видео

У «Видео» вместо коррекции — настоящие атрибуты тега <video>, которые имеют смысл именно для видео: autoplay, loop, muted, playsinline и controls — переключатели, preload — выпадающий список (none / metadata / auto). Они меняются вживую прямо в превью — например, включить «Элементы управления», чтобы проверить, как будет выглядеть готовый плеер. По умолчанию: автовоспроизведение, зацикливание, без звука и playsinline включены, элементы управления выключены, preload="auto" — то есть видео сразу проигрывается как фон, без интерфейса плеера. Подписи берутся из labels.videoSettings и labels.videoPreload.

Квадратная кнопка «Сбросить» появляется при наведении на файл, если хотя бы один параметр (ползунок коррекции или настройка видео) сдвинут с значения по умолчанию, и возвращает их все разом. Опция sources сужает набор кнопок над образцом цвета — например, оставить только загрузку видео. 

<input type="text" value="#4C9FFE" v-filler>

С единственным доступным источником кнопки-переключатели не показываются:

<input type="text" value="#4C9FFE" v-filler="{ sources: ['video'] }">

Отключённое поле

<input type="text" value="#9E9E9E" data-alpha="40" v-filler="{ disabled: true }">
