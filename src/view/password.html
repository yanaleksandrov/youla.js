Пароль (password)

password — готовый компонент для поля ввода пароля: проверяет пароль на соответствие политике (строчные и ПРОПИСНЫЕ буквы, цифры, спецсимволы, минимальная длина), показывает индикатор надёжности, умеет сгенерировать пароль, который сразу проходит все правила, и переключает показ/скрытие введённых символов. Всё это — без единой строчки собственного JavaScript.

Чтобы подключить компонент, повесьте v-data="password" на общий контейнер — дальше все его свойства и методы доступны прямо в разметке внутри этого контейнера, а поле, индикатор и список правил обновляются автоматически при каждом изменении пароля.

  • 2+ строчные буквы
  • 2+ ПРОПИСНЫЕ буквы
  • 2+ цифры
  • 2+ спецсимвола
  • Не короче 12 символов
<div v-data="password">
  <input :type="visible ? 'text' : 'password'" v-prop="value" @input="check(value)"
    placeholder="Придумайте пароль">
  <button type="button" @click="toggle()" v-text="visible ? 'Скрыть' : 'Показать'"></button>
  <button type="button" @click="generate()">Сгенерировать пароль</button>

  <div class="password-meter">
    <div class="password-meter__bar" :class="`level-${level()}`" :style="{ width: `${progress}%` }"></div></div>
  <div v-text="value && label()"></div>

  <ul class="password-rules">
    <li :class="valid.lowercase && 'is-done'">2+ строчные буквы</li>
    <li :class="valid.uppercase && 'is-done'">2+ ПРОПИСНЫЕ буквы</li>
    <li :class="valid.digit && 'is-done'">2+ цифры</li>
    <li :class="valid.special && 'is-done'">2+ спецсимвола</li>
    <li :class="valid.length && 'is-done'">Не короче 12 символов</li>
  </ul>
</div>

Разметку и стили демо можно менять как угодно под свой дизайн — компонент не привязан к конкретным классам или тегам. Единственное, что важно сохранить: v-prop="value" и @input="check(value)" на поле ввода, и вызовы toggle() / generate() на своих кнопках.

Кнопка «Сгенерировать пароль» — самый простой способ сразу получить пароль, который проходит политику: generate() сам подставляет результат в поле и обновляет индикатор надёжности, отдельно вызывать check() не нужно.

Сама политика (минимальное количество символов каждого типа, минимальная длина и допустимые символы) задаётся в исходнике компонента через min и charsets — чтобы изменить требования под свой проект, скопируйте компонент и поменяйте эти значения.

Свойства и методы password вкратце

Имя Когда использовать
value Текущий пароль. Читайте его, если нужно показать сам пароль где-то ещё на странице
visible true, если пароль сейчас показан открытым текстом. Пригодится, если хотите завязать на него что-то своё — например, другую иконку глаза вместо текста кнопки
toggle() Переключает visible — вызывайте по клику на своей кнопке «Показать/Скрыть»
generate() Вставляет в поле готовый пароль, который сразу проходит все правила политики
check(value) Пересчитывает индикатор и список правил под переданную строку. Нужен только на @input поля ввода — при ручном вводе пароля
valid Что из политики уже выполнено — флаги lowercase, uppercase, special, digit, length. Используйте, чтобы подсветить конкретные невыполненные правила, как в примере выше
progress Общий процент готовности пароля (0–100) — удобно для полосы индикатора. Растёт постепенно: например, одна прописная буква из двух требуемых уже даёт часть «очков», а не ноль
level() / label() Если полоски прогресса недостаточно — level() даёт ступень от 0 до 4, а label() готовую подпись к ней («Слишком слабый» … «Отличный»)
min, charsets Сама политика: сколько символов каждого типа требуется и минимальная длина (min), какие символы считаются каждым типом (charsets). Меняются только в исходнике компонента — общего для всех полей на странице
