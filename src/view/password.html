Пароль (password)

password проверяет пароль на соответствие политике (минимум строчных, ПРОПИСНЫХ, цифр и спецсимволов, а также общая длина), умеет сгенерировать пароль, который этой политике сразу соответствует, и переключает показ/скрытие введённых символов — три задачи одним готовым компонентом.

Он зарегистрирован через Youla.data('password', callback), а не Youla.method() — как и любой другой именованный компонент (modal, toasts), он привязывается к элементу через v-data="password" и живёт, пока этот элемент на странице. Благодаря этому value и результат последней проверки (valid, progress) — обычные реактивные свойства: их можно читать прямо в v-show, :class и v-text где угодно внутри компонента, без промежуточной переменной в обработчике события. 

<div v-data="password">
  <input :type="visible ? 'text' : 'password'" v-prop="value" @input="check(value)"
    placeholder="Придумайте пароль">
  <button type="button" @click="visible = toggle(visible)" v-text="visible ? 'Скрыть' : 'Показать'"></button>
  <button type="button" @click="generate()">Сгенерировать пароль</button>

  <div class="password-meter">
    <div class="password-meter__bar" :class="`level-${level()}`" :style="{ width: `${progress}%` }"></div>
  </div>
  <div v-text="value && label()"></div>

  <ul class="password-rules">
    <li :class="valid.lowercase && 'is-done'">2+ строчные буквы</li>
    <li :class="valid.uppercase && 'is-done'">2+ ПРОПИСНЫЕ буквы</li>
    <li :class="valid.digit && 'is-done'">2+ цифры</li>
    <li :class="valid.special && 'is-done'">2+ спецсимвола</li>
    <li :class="valid.length && 'is-done'">Не короче 12 символов</li>
  </ul>
</div>
  • 2+ строчные буквы
  • 2+ ПРОПИСНЫЕ буквы
  • 2+ цифры
  • 2+ спецсимвола
  • Не короче 12 символов

Каждый атрибут читает свойства password прямо по имени — check(value), toggle(visible), level() и остальные — без this: как и в любом выражении разметки, данные компонента доступны напрямую, а не через объект-обёртку.

generate() сам записывает результат в value и сразу вызывает check() — кнопке достаточно одного вызова, без сборки выражения из нескольких частей.

Свойства и методы password вкратце

Имя Что делает
value Текущий пароль — сюда же пишет v-prop при вводе и generate() при генерации
visible Показывать ли пароль как обычный текст — переключается кнопкой «Показать/Скрыть»
valid Булевы флаги последней проверки — lowercase, uppercase, special, digit, length — каждый true, если соответствующее правило выполнено
progress Общий процент выполнения политики (0–100), с учётом частичного соответствия — например, одна прописная буква из двух требуемых даёт половину «очков» за это правило, а не ноль
level() / label() level() округляет progress до ступени от 0 до 4, а label() превращает её в понятную подпись — от «Слишком слабый» до «Отличный» (список ступеней — в labels)
check(value) Пересчитывает valid и progress для переданной строки
generate() Записывает в value готовый пароль, который сразу соответствует всем правилам (по 2 символа каждого типа, не короче 12 символов) — символы не идут подряд по типу благодаря shuffle() — и обновляет valid/progress
shuffle(password) Перемешивает символы переданной строки (алгоритм Фишера — Йейтса)
toggle(value) Инвертирует переданное булево значение — toggle(true) вернёт false, и обратно. Общий переключатель, которым кнопка меняет visible. Назван не switch, потому что это зарезервированное слово JS — его нельзя вызвать как обычный идентификатор прямо в выражении разметки
min, charsets Сама политика: минимальные количества символов каждого типа и длина (min) и наборы символов, из которых они берутся (charsets)
