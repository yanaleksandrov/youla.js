Variables

Youla.js прокидывает в каждое выражение четыре особые переменные — $el, $event, $refs и $root. Они не хранятся в данных компонента и не объявляются в v-data — библиотека подставляет их сама, поэтому они доступны сразу везде, где допустимо JS-выражение: в обработчиках событий, в значении v-text, v-show, :class и любой другой директивы.

Внутри метода, вызванного из такого выражения (например, зарегистрированного через Youla.data() или Youla.method()), те же переменные доступны как this.$el, this.$event, this.$refs и this.$root — без явной передачи их аргументом.

$el

DOM-элемент, на котором объявлено текущее выражение — не корень компонента, а именно тот элемент, чей атрибут сейчас вычисляется. У каждого элемента своё значение $el. 

<div v-data>
  Тег этого элемента: <strong v-text="$el.tagName"></strong>
</div>
Тег этого элемента:

$el вычисляется на <strong>, а не на обёртывающем <div v-data> — поэтому в тексте появляется STRONG, а не DIV. Так же $el использует и сама директива v-prop внутри себя, чтобы прочитать текущее значение поля формы ($el.value, $el.checked) без явного упоминания элемента в разметке.

$event

Объект события браузера, вызвавшего обработчик. В отличие от остальных трёх переменных, $event имеет смысл только внутри выражения @событие — снаружи обработчика события не существует, поэтому там она равна undefined. 

<div v-data="{ lastKey: '' }">
  <input @keyup="lastKey = $event.key" placeholder="Печатайте здесь">
  <p>Последняя нажатая клавиша: <strong v-text="lastKey"></strong></p>
</div>

Последняя нажатая клавиша:

Готовые модификаторы вроде .prevent и .stop — это просто сокращения для вызова $event.preventDefault() и $event.stopPropagation(); подробности — на странице События.

$refs

Доступ к элементам компонента, помеченным атрибутом v-ref, по их имени — без document.querySelector и без хранения ссылки на элемент в данных. 

<div v-data>
  <input v-ref="email" type="email" placeholder="you@example.com">
  <button @click="$refs.email.focus()">Перейти к полю</button>
</div>

$refs ищет элемент только внутри своего компонента и не видит v-ref-элементы вложенных компонентов. Динамические имена через v-bind и другие детали — на странице v-ref.

$root

Корневой элемент компонента — тот самый, на котором объявлен v-data. Удобен, когда из глубоко вложенного элемента нужно достать до корня, не расставляя v-ref по всей разметке. 

<div v-data>
  <div>
    <div>
      <button @click="$root.style.background = '#fef3c7'">Подсветить компонент</button>
    </div>
  </div>
</div>

Кнопка вложена на три уровня внутрь, но $root всё равно указывает на внешний <div v-data>, а не на своего непосредственного родителя.

Внутри методов: this.$el, this.$event, this.$refs, this.$root

Когда выражение вызывает метод компонента, this внутри него — те же реактивные данные, что и в любом другом методе v-data, только с четырьмя переменными поверх них. Это избавляет от необходимости передавать $el, $event, $refs и $root в метод аргументами вручную. 

Youla.data('card', () => ({
  status: 'Нажмите кнопку',

  inspect() {
    const { $el, $event, $root, $refs } = this;

    this.status = `Элемент: <${$el.tagName.toLowerCase()}>, ` +
      `событие: "${$event.type}", ` +
      `корень: <${$root.tagName.toLowerCase()}>, ` +
      `поле по ссылке: ${$refs.note.value || '(пусто)'}`;
  },
}));

<div v-data="card">
  <input v-ref="note" placeholder="Впишите что-нибудь">
  <button @click="inspect()">Проверить переменные</button>
  <p v-text="status"></p>
</div>

this.$el здесь — сама кнопка, а не корневой <div>, потому что выражение inspect() объявлено именно на ней. Полная сводная таблица всех специальных переменных, включая $имяМетода для методов Youla.method(), — на странице Полный синтаксис.
