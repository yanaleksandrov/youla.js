v-each

Директива v-each позволяет создавать элементы DOM, перебирая массив, объект или диапазон чисел. Для каждого элемента исходных данных клонируется тот DOM-узел, на котором указана директива, поэтому итоговая разметка всегда отражает актуальное состояние данных. Вот простой пример создания списка цветов на основе массива. 

<div v-data="{ colors: ['Red', 'Orange', 'Yellow'] }">
  <ul>
    <li v-each="color in colors" v-text="color"></li>
  </ul>
</div>

Обратите внимание на важное правило: атрибут v-each должен находиться именно на том элементе-шаблоне, который нужно повторить для каждой итерации цикла, а не на его родителе или потомке. Сам элемент-шаблон остаётся в разметке (он используется как образец для клонирования), поэтому его стоит скрыть, добавив css правило display: none для селектора [v-each].

Вы также можете передавать объекты и разбирать их следующим синтаксисом:

  <ul v-data="{ cars: { make: 'Jeep', model: 'Grand Cherokee', color: 'Black' } }">
    <li v-each="(car, key) in cars">
      <span v-text="key"></span>: <span v-text="car"></span>
    </li>
  </ul>

Массив объектов

Самый частый случай на практике — перебор массива объектов. Внутри шаблона доступны любые поля текущего элемента через точечную нотацию. 

<ul v-data="{
  users: [
    { name: 'Ian', role: 'Admin' },
    { name: 'Olga', role: 'Editor' },
    { name: 'Denis', role: 'Viewer' },
  ]
}">
  <li v-each="user in users">
    <strong v-text="user.name"></strong> — <span v-text="user.role"></span>
  </li>
</ul>
  • —

А также создавать вложенные циклы с неограниченной глубиной

<div v-data="{
  categories: [
    {
      name: 'Category 1',
      products: [
        { name: 'Product 1' },
        { name: 'Product 2' },
      ]
    },
    {
      name: 'Category 2',
      products: [
        { name: 'Product 3' },
        { name: 'Product 4', attributes: ['30x40mm', 'White'] },
        { name: 'Product 5', attributes: ['20x20mm', 'Black'] },
      ]
    }
  ]
}">
  <div v-each="(category, index) in categories">
    <h3 v-text="category.name"></h3>
    <ul>
      <li v-each="product in category.products">
        <strong v-text="product.name"></strong>
        Attributes:
        <em v-each="attribute in product.attributes join ', '" v-text="attribute"></em>
      </li>
    </ul>
  </div>
</div>

Независимость списков друг от друга

Каждый блок v-data — самостоятельный компонент со своими данными. Это значит, что можно свободно располагать на одной странице сколько угодно независимых v-each, в том числе вложенных, и даже использовать в них одинаковые имена переменных — области видимости соседних компонентов друг с другом не пересекаются. 

<ul v-data="{ fruits: ['Apple', 'Banana'] }">
  <li v-each="item in fruits" v-text="item"></li>
</ul>

<ul v-data="{ tools: ['Hammer', 'Wrench'] }">
  <li v-each="item in tools" v-text="item"></li>
</ul>

Добавление разделителя

Ключ join позволяет вставлять текстовый разделитель между элементами. Это упрощает создание списков, автоматически добавляя нужный символ (например, запятую, пробел или слэш) между элементами. 

<p v-data="{ attributes: ['White', '20x30mm', 'Google LLC'] }">
  Характеристики: <i v-each="attribute in attributes join ', '" v-text="attribute"></i>
</p>

Доступ к индексам

Если вам нужно получить доступ к индексу каждого элемента в итерации, вы можете сделать это, используя следующий синтаксис: (item, index) in items 

<ul v-data="{ names: ['Ivan', 'Yulia', 'Evgeny'] }">
  <li v-each="(name, index) in names">
    <span v-text="`${++index}: ${name}`"></span>
  </li>
</ul>

Динамическое обновление списка

Список реактивен: как только массив, на основе которого он построен, получает новое значение, v-each перерисовывает разметку автоматически. Обратите внимание, что изменять список нужно присваиванием нового значения (например, через spread-синтаксис или .slice()), а не мутирующими методами вроде .push() — именно присваивание отслеживается системой реактивности. 

<div v-data="{ fruits: ['Apple', 'Banana'] }">
  <button type="button" @click="fruits = [...fruits, 'Cherry']">Добавить</button>
  <button type="button" @click="fruits = fruits.slice(0, -1)">Удалить последний</button>
  <ul>
    <li v-each="fruit in fruits" v-text="fruit"></li>
  </ul>
</div>

Итерация по диапазону

Если вам нужно просто зациклить несколько раз, а не перебирать массив, Youla.js предлагает короткий синтаксис с указанием целого числа вместо свойства:

<div v-data>
  Рейтинг:
  <span v-each="i in 5">⭐</span>
</div>
Рейтинг: ⭐

Обратите внимание, что в таком случае значения i начинаются с 1, а не с 0.

Модификаторы

.lazy

Предотвращает рендеринг списка при инициализации компонента и запускает рендер только при изменении привязанных данных. Это особенно полезно для предотвращения эффекта «flickering» (мерцания страницы) страницы и улучшения SEO-оптимизации.

Как это работает

Первичный рендеринг реализуется через серверную часть: браузер сразу отображает контент, не дожидаясь загрузки JS или данных. После загрузки JS, происходит гидратация: Youla.js "привязывает" данные к уже отрендеренному HTML, обеспечивая интерактивность и возможность динамического обновления. 

<div v-data="{devices: []}">
  <button type="button" @click="devices = ['Headphones', 'VR Glasses']">Обновить список</button>
  <ul>
    <li v-each.lazy="device in devices" v-text="device"></li>
    <li>Phones</li>
    <li>Laptops</li>
  </ul>
</div>
  • Phones
  • Laptops

Та же идея с тем же названием модификатора есть и у v-show — для тех же целей, но применительно к видимости отдельного элемента, а не к списку. Если помимо цикла на элементе нужны и другие директивы, события и атрибуты одним набором, посмотрите v-bind.
