Модальное окно

Модальное окно строится из типовых частей: показ/скрытие по флагу (v-show), закрытие кликом по фону или клавишей Escape, блокировка прокрутки страницы и ARIA-атрибуты для доступности.

По отдельности каждая часть простая, но на двух элементах — фоне и окне — вместе они превращаются в длинный список атрибутов.

v-bind собирает атрибуты, директивы и события элемента в один именованный набор внутри Youla.data — в разметке остаётся только v-bind="имя". 

document.addEventListener('youla:init', () => {
  Youla.data('modal', () => ({
    open: false,
    show() {
      this.open = true;
      document.body.style.overflow = 'hidden';
    },
    hide() {
      this.open = false;
      document.body.style.overflow = '';
    },
    backdrop: {
      'v-show': 'open',
      ':aria-hidden': '!open',
    },
    panel: {
      'role': 'dialog',
      ':aria-modal': 'open',
      '@click.stop'() {},
      '@click.outside'() {
        this.hide();
      },
    },
  }));
});

<div v-data="modal" @keydown.esc.window="hide()">
  <button type="button" @click="show()">Открыть модальное окно</button>

  <div class="modal-backdrop" v-bind="backdrop">
    <div class="modal-window" v-bind="panel">
      <h3>Заголовок окна</h3>
      <p>Закрыть можно кликом по фону, клавишей Escape или кнопкой ниже.</p>
      <button type="button" @click="hide()">Закрыть</button>
    </div>
  </div>
</div>

Модификатор .esc сам фильтрует нажатую клавишу и сочетается с .window в любом порядке — один атрибут слушает нажатие на всей странице, но реагирует только на Escape. Подробнее о модификаторах клавиш — на странице События.

Кнопка открытия и обработчик Escape остались обычными атрибутами прямо в разметке: на элементе всего одна динамическая привязка, оборачивать её в v-bind смысла нет.

Заголовок окна

Закрыть можно кликом по фону, клавишей Escape или кнопкой ниже.

show() и hide() — обычные методы: изменение open и работа с document.body происходят в одном месте, а не размазаны по разметке.

backdrop и panel — свойства (не методы) со строками-выражениями и парой обработчиков внутри: строки читают open так же, как если бы были написаны прямо в разметке.
